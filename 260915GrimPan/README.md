# Grimpan · 함께 그리고, 이어 그리기

사람과 에이전트가 같은 그림을 편집하는 정적 웹앱입니다. 그림을 링크로 공유하고, 받은 그림을 **직접 인용해 포크**하면 원본을 보관한 새로운 보드가 만들어집니다.

- **배포 주소:** https://studyreadbook4ever.github.io/myChangGo/260915GrimPan/
- HTML / CSS / JavaScript ES modules. 실행에 외부 라이브러리·백엔드·API 키가 필요하지 않습니다.
- Chrome 155 WebMCP의 `document.modelContext`와 JavaScript 객체 인자 형식을 사용합니다.
- WebMCP를 지원하지 않는 브라우저에서도 사람의 편집, 공유·포크, 로컬 에이전트 데모는 사용할 수 있습니다.

## 사용하기

1. 펜, 도형, 선, 텍스트로 그림을 그립니다. 선택 도구로 객체를 옮기거나 Shift로 여러 개 선택합니다. 글자는 더블클릭해서 수정할 수 있습니다.
2. **공유하기**에서 스냅샷 링크를 복사해 전달합니다. 링크에는 그 순간의 편집 가능한 데이터와 인용 원본이 들어갑니다. 이후 수정은 새 링크로 공유합니다.
3. 링크를 받은 사람은 원본을 읽기 전용으로 봅니다. **포크하기**를 누르면 별도 ID의 새 보드가 만들어집니다.
4. 일부만 선택한 뒤 **선택 인용**을 누르면 해당 객체만 가져온 새 보드가 만들어집니다. 전체 원본은 출처에 함께 보관합니다.
5. **출처 → 원본 열기**에서 앞선 그림을 같은 엔진으로 열 수 있습니다. 여러 번 포크해도 이전 원본을 다시 열고 또 포크할 수 있습니다.
6. **내 보드**는 현재 브라우저의 작업 모음입니다. **파일로 저장 / 가져오기**로 프로젝트 JSON, PNG, SVG를 저장하거나 프로젝트를 가져올 수 있습니다.

### 키보드와 터치

| 키 | 동작 |
|---|---|
| V / B / R / O / L / T / N / E / H | 선택 / 펜 / 사각형 / 원 / 선 / 텍스트 / 메모 카드 / 객체 지우개 / 화면 이동 |

| 휠 | 포인터 중심 확대·축소 |

| 방향키 / Shift + 방향키 | 선택 객체 1 / 10 단위 이동 |

모바일에서는 하단 설정 패널을 스크롤할 수 있습니다. 한 손가락으로 그리거나 화면 이동 도구로 보드를 이동하세요.

## 그림으로 소통하기

- **메모 카드와 말풍선:** 보드를 클릭해 텍스트가 들어간 객체를 추가합니다. 더블클릭해 내용을 수정하고, 선택해서 색·글자 크기·위치를 바꿀 수 있습니다.
- **닉네임과 이모지 반응:** 먼저 닉네임을 정한 뒤 👍 ❤️ ✨ 💡 👏 ❓ 반응을 남깁니다. 읽기 전용 원본에 반응하면 원본을 포크한 새 보드에 기록합니다. 같은 닉네임·이모지는 다시 누르면 취소됩니다.
- **인용해 이어 그리기:** 원본을 새 보드로 포크하고 새로운 그림·말풍선·반응을 더해 새 링크로 공유합니다. 댓글과 답글 기능은 없습니다.
- **장면:** 현재 화면이나 선택 영역을 제목·설명과 함께 저장합니다. 공유받은 사람도 같은 순서로 장면을 볼 수 있습니다. 발표 보기에서 좌우 방향키로 이동합니다.
- **원본과 나란히 비교:** 출처 카드의 비교 버튼으로 원본과 현재 그림을 함께 봅니다.
- **현재 보드에 인용:** 파일 메뉴에서 받은 공유 링크를 붙여넣고, 원본 전체를 출처로 보관하며 그림과 장면을 현재 보드에 가져옵니다. 한 번의 Undo로 인용 전체를 되돌릴 수 있습니다.

### 닉네임과 개인정보

로그인·계정·비밀번호·인증 토큰·인증 쿠키를 만들거나 저장하지 않습니다. 닉네임 설정은 JavaScript 메모리, 즉 **현재 탭에서만** 유지하며 새로고침하면 다시 정합니다. 닉네임은 인증된 신원이 아닌 표시 이름입니다.

그림의 작성자 이름과 이미 남긴 이모지 반응의 닉네임은 **공개할 그림 데이터의 일부**입니다. 다른 그림 요소와 함께 기기에 저장되고 공유 링크·프로젝트 파일에 포함됩니다. 닉네임 설정 자체를 localStorage나 sessionStorage에 보관하지 않습니다. 댓글·답글 데이터는 프로젝트 형식에 포함하지 않습니다.

## 에이전트

### 직접 움직여 보기

에이전트 탭의 **보라**는 위치와 펜 상태를 가진 보드 위의 커서입니다. 방향 버튼으로 이동하고 펜을 켜면 이동 경로가 그려집니다. 별·정원 데모는 미리 작성된 도구 명령의 재생입니다. **AI 모델이 아니며 네트워크 추론을 실행하지 않습니다.** 멈추기 버튼 또는 사람의 그리기 동작으로 데모를 멈출 수 있습니다.

### Chrome 155 네이티브 WebMCP

실험 기능을 제공하는 Chrome 155에서 `WebMCP` / `WebMCPTesting` 기능을 활성화합니다. 이 API는 실험 중이므로 버전과 기능 존재 여부를 확인해야 합니다. 별도 AI 에이전트는 브라우저 연결을 통해 다음처럼 도구를 발견하고 호출합니다.

```js
const tools = await document.modelContext.getTools();
const move = tools.find(tool => tool.name === 'agent_move');
const result = await document.modelContext.executeTool(move, { dx: 80, dy: 0 });
console.log(JSON.parse(result));
```

인자는 **JavaScript 객체**입니다. 도구 결과는 구조화된 결과를 담은 JSON 문자열입니다. 이 둘을 구분하세요. 앱은 기존 `navigator.modelContext`를 흉내 내거나 가짜 네이티브 지원 상태를 표시하지 않습니다.

모든 브라우저에서 같은 핸들러를 직접 호출할 수도 있습니다.

```js
await window.grimpan.ready;
await window.grimpan.call('agent_pen', { down: true, color: '#7160d8', width: 3 });
await window.grimpan.call('agent_move', { x: 400, y: 300 });
const state = await window.grimpan.call('board_read', { limit: 20 });
```

도구 13개: `board_read`, `board_select`, `board_edit`, `agent_move`, `agent_turn`, `agent_pen`, `board_view`, `board_history`, `board_share`, `board_fork`, `board_quote`, `board_identity`, `board_react`.

## 공유와 데이터의 동작

- 스냅샷은 압축된 URL fragment(`#board=…`)에 들어갑니다. 그림을 저장하기 위한 서버 요청은 없습니다. 정적 앱 파일은 GitHub Pages에서 받습니다.
- 공유 링크는 불변 스냅샷입니다. 실시간 다중 사용자 편집이나 중앙 게시판이 아닙니다. 서로 링크나 파일을 주고받으며 그림으로 대화합니다.
- 긴 링크는 메신저에서 잘릴 수 있습니다. 앱은 긴 링크를 안내하고 `.grimpan.json` 파일도 제공합니다. 파일 역시 같은 엔진으로 열고 포크할 수 있습니다.
- 출처는 SHA-256 식별자와 실제 원본 스냅샷을 함께 보관합니다. 조상 스냅샷은 평탄한 구조로 저장해 재귀적인 URL 증가를 피합니다. 가져온 출처의 내용과 해시 일치를 검사합니다.
- 작성자 이름은 사용자가 적는 값입니다. 콘텐츠 해시는 작성자의 신원이나 저작권을 인증하지 않습니다.
- 프로젝트는 최대 **3 MiB의 정규화된 JSON**, 보드당 **3,000개 객체 / 100,000개 경로 점**, 최대 **64개 인용 원본**을 지원합니다. 인용 원본을 포함한 전체 크기가 제한에 포함됩니다. 초과 데이터는 조용히 잘라내지 않고 오류를 돌려줍니다.
- 자동 저장은 IndexedDB를 사용합니다. 사용할 수 없으면 명시적으로 안내한 뒤 localStorage를 시도합니다. 저장 공간 부족을 성공으로 표시하거나 이전 보드를 자동 삭제하지 않습니다. 중요한 작업은 프로젝트 파일로 보관하세요.

## 엔진 구조

```text
사람의 포인터/키보드 ─┐
                    ├─ engine.js 명령·검증·이력 ─ 객체 상태 ─ SVG 화면
WebMCP/로컬 도구 ────┘                           └─ 상태 조회
                              │
                     share.js 스냅샷·원본·포크
                              │
                     storage.js 기기 내 작업 저장
```

픽셀 스크린샷 대신 객체·텍스트·획을 보관합니다. 하나의 배치는 하나의 Undo 단위이며, 배치 중 실패는 부분 반영되지 않습니다. 사람과 에이전트가 같은 이력을 사용합니다. Undo/Redo 후에도 문서 revision은 증가합니다. 가져온 원본의 ID와 revision은 그대로 보존합니다.

새 기능은 엔진 명령 → UI → 도구 스키마와 핸들러 순서로 확장할 수 있습니다. 도구의 모든 입력은 실행 전 검증합니다. 가져온 프로젝트에서 코드를 실행하지 않으며, 텍스트는 SVG 텍스트 노드로 렌더링합니다.

## 로컬 실행과 테스트

저장소 상위 폴더에서:

```sh
python3 -m http.server 8766
```

http://localhost:8766/260915GrimPan/ 를 엽니다. ES modules를 사용하므로 파일을 직접 더블클릭하기보다 정적 서버로 열어주세요.

앱 폴더에서 Node 22 이상으로:

```sh
npm test
```

엔진의 원자적 배치·Undo·읽기 전용, Unicode 공유, 여러 세대의 원본 복구, 압축 해제 크기 제한, 데이터 위변조 거부, 저장 실패, WebMCP 스키마·핸들러 일치를 검사합니다. 네이티브 연결과 실제 화면 편집은 Chrome 155 브라우저 검증으로 별도 확인합니다. 브라우저 검증에만 Playwright 개발 의존성을 사용하며, 배포 앱은 이 라이브러리를 불러오지 않습니다.

```sh
npm ci --ignore-scripts
# Chrome 155를 별도 프로필로 --remote-debugging-port=9235
# --enable-blink-features=WebMCP,WebMCPTesting 옵션으로 실행한 뒤:
npm run test:browser
```

`GRIMPAN_BASE_URL`, `GRIMPAN_CDP_URL`, `GRIMPAN_REPORT_DIR`로 검증 대상과 결과 위치를 바꿀 수 있습니다. 테스트는 격리된 브라우저 컨텍스트를 사용합니다.
