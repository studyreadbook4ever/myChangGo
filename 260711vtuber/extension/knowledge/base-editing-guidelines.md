# 기본 키리누키 편집 지침

## 사용자 선택 구간

- 사용자가 기록한 시작·끝 스탬프는 `authority: USER`인 확정 컷 경계다.
- AI와 후속 에이전트는 선택 구간을 자동으로 확장·축소·병합·삭제하지 않는다.
- 음성 인식 정확도를 위해 경계 밖 문맥을 임시로 읽을 수는 있지만, 결과 영상과 자막 cue에는 선택 범위 밖 내용을 포함하지 않는다.
- 문장이나 반응이 잘려 보이더라도 경계를 조용히 바꾸지 않는다. 더 나은 경계는 검수 메모에 선택적 제안으로만 남긴다.
- 컷 경계 변경은 사용자가 통합 편집기의 핸들을 움직이거나 명시적으로 요청한 경우에만 적용한다.

## 구간 연결

- 별도 요청이 없으면 사용자가 저장한 순서대로 연결한다.
- 서로 겹치는 선택도 자동으로 병합하거나 중복 제거하지 않는다.
- 전환 효과나 여백을 넣기 위해 원본 선택 범위를 늘리지 않는다.
- 순서 변경과 구간 비활성화는 사용자의 명시적 편집으로만 수행한다.

## 한국어 자막

- 발화 내용을 충실히 옮기되 반복어와 추임새 정리는 의미와 캐릭터를 훼손하지 않는 범위에서만 한다.
- 들리지 않거나 확신할 수 없는 단어를 창작하지 않는다. 불확실한 부분은 검수 메모에 원본 시각과 함께 남긴다.
- 말로 인식된 구간은 알아듣기 어렵다는 이유로 생략하지 않는다. 가능한 원문을 유지하고 사람 검수가 필요하다고 표시한다.
- 자막은 한 화면에서 읽기 좋은 호흡으로 나누며 하나의 표시 시간은 최대 4초다. 컷 이후의 영상 타임라인에 다시 맞춘다.
- 문장 끝 마침표는 넣지 않고, 의미에 필요한 물음표·느낌표는 유지한다.
- 번역이 필요한 외국어 발화는 한국어 의미 자막을 제공하되 고유명사와 게임 용어는 문맥을 확인한다.

## 결과와 검수

- 원본 파일은 변경하지 않는다.
- 자동 게시·업로드·삭제는 수행하지 않는다.
- 사람이 컷 경계, 자막, 저작권·방송인 규정을 검수할 수 있도록 편집 계획과 검수 메모를 함께 제공한다.
- 영상 처리에 실패한 구간을 조용히 누락하지 말고 실패 원인과 해당 사용자 선택을 기록한다.
