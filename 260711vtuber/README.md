# 치지직·YouTube 키리누키 스튜디오

치지직 생방송·다시보기와 YouTube VOD를 보며 사용할 구간을 표시하고, 같은
Chrome Extension의 전체화면 편집기에서 컷·투명 이미지·구간별 음성·다중
한국어 자막을 검수해 영상을 내보내는 로컬 우선 도구입니다.

사용자가 찍은 시작·끝과 순서는 `authority: USER`인 확정 범위입니다. 자동
로직은 재미있는 구간을 대신 고르거나 경계를 조용히 늘리거나 줄이지 않습니다.
영상 중간 삭제, 컷 순서 변경, 자막과 이미지 배치는 사람이 직접 결정합니다.

자막 초벌은 **AudSeg만** 사용합니다. AudSeg는 브라우저 안에서 오디오 활동
구간을 찾아 최대 4초의 빈 cue를 만들 뿐, 말을 글로 바꾸거나 화자·언어를
판정하지 않습니다. 모든 자막 글과 화자 색은 사람이 원음을 듣고 채워야 합니다.
모델, 계정, 비밀 키, 별도 로컬 프로세스는 필요하지 않습니다.

## 실행 준비

요구 환경:

- Node.js 20.9 이상
- Chrome 또는 Chromium 120 이상
- 로컬 원본 영상

저장소의 `260711vtuber` 폴더에서 사람용 설정 도우미를 실행합니다.

```bash
./setup.sh
./kirinuki.sh start "https://chzzk.naver.com/video/..."
```

도우미는 필요한 시스템 패키지를 임의로 설치하지 않고 준비 상태와 설치
힌트를 보여 준 뒤, 고정된 npm 의존성·Extension 번들·라이선스 경계를
검증합니다. 자동 열기는 Chromium을 사용합니다. 일반 Google Chrome을 쓸
때는 아래 수동 절차를 따르면 됩니다.

명령을 직접 실행하려면:

```bash
npm ci --ignore-scripts
npm run build
npm run validate
```

그다음 브라우저에서:

1. `chrome://extensions`를 엽니다.
2. 우측 상단 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다**를 누릅니다.
4. 이 폴더의 `extension` 디렉터리를 선택합니다.
5. 치지직 또는 YouTube 영상 탭에서 도구 모음의 확장 아이콘을 누릅니다.

이미 열려 있던 영상 탭은 한 번 새로고침해야 연결될 수 있습니다. Extension
폴더의 절대 경로를 옮기면 브라우저가 다른 설치로 인식할 수 있으므로, 새
위치의 폴더를 다시 불러오세요. 중요한 프로젝트는 이동 전에 JSON으로
내보내 보관하세요.

## 지원 소스

- 치지직 생방송
- 치지직 다시보기
- YouTube 일반 VOD
- YouTube Shorts
- 최상위 탭으로 연 YouTube embed

진행 중인 YouTube 라이브와 다른 사이트 안의 임의 iframe은 지원하지 않습니다.
YouTube 광고가 재생 중이면 광고 시각이 프로젝트 좌표에 섞이지 않도록 캡처를
막습니다.

Extension은 영상 메타데이터와 현재 재생 시각을 연결하지만 원본을 내려받거나
접근 제한을 우회하지 않습니다. 본인이 소유하거나 편집 권한을 받은 로컬 파일을
직접 준비해 편집기에 연결해야 합니다.

권한 있는 YouTube VOD를 별도 도구로 준비할 때 제공된 명령을 사용할 수
있습니다.

```bash
npm run acquire:youtube -- --profile quality-first \
  --output-dir "/절대/저장/폴더" \
  "https://www.youtube.com/watch?v=..."
```

다운로드 가능 여부와 게시·저작권 조건은 사용자가 확인해야 합니다.

## 한 바퀴 작업 흐름

1. 지원 영상 페이지를 재생합니다.
2. 사건이 시작될 때 **시작 스탬프 → 지금**을 누릅니다.
3. 반응이나 결론이 끝날 때 **끝 스탬프 → 지금**을 누릅니다.
4. 선택 메모를 확인하고 **구간 저장**을 누릅니다.
5. 필요한 컷을 모두 저장한 뒤 **통합 편집기에서 열기**를 누릅니다.
6. **원본 연결**에서 권한 있는 같은 영상의 로컬 파일을 고릅니다.
7. 페이지 시각과 파일 시각이 다르면 정렬 오프셋을 맞춥니다.
8. 컷 경계와 순서를 확인합니다.
9. **활성 컷 전체 초벌 만들기**로 AudSeg 빈 타이밍을 실행합니다.
10. 모든 빈 cue를 재생하며 자막 글·화자·색·시작·끝을 직접 입력합니다.
11. 이미지, 음성 자동화와 자막 배치를 검수합니다.
12. 임시저장 후 영상·프로젝트 JSON·SRT를 내보냅니다.

## 사용자 확정 컷

사이드패널에서 저장한 구간은 입력 권위입니다.

- 자동 로직은 새 컷을 고르지 않습니다.
- 경계를 자동 확장·축소하지 않습니다.
- 겹치는 선택을 자동 병합하거나 버리지 않습니다.
- 컷 순서를 자동 변경하지 않습니다.
- 사람이 편집기에서 손잡이, 숫자 입력 또는 명시적 삭제 도구를 쓸 때만
  결과 타임라인이 바뀝니다.

여러 컷을 체크한 뒤 그룹 이동 버튼이나 `Alt+↑`, `Alt+↓`로 순서를 바꿀 수
있습니다.

### 영상 중간 구간 삭제

컷 양끝을 줄이는 것과 별개로 가운데 부분을 통째로 덜어낼 수 있습니다.

1. 삭제 시작점에 재생헤드를 두고 **시작 I**를 누릅니다.
2. 삭제 끝점에서 **끝 O**를 누릅니다.
3. 범위를 다시 확인하고 **구간 삭제**를 누릅니다.

삭제 뒤의 영상, 이미지, 음성 설정과 자막은 같은 시간만큼 앞으로 이동합니다.
삭제 범위와 겹친 항목은 남은 영상 조각에 맞춰 잘리거나 분할됩니다. 큰 삭제
전에는 **지금 임시저장**을 권장합니다.

## 페이지 시각과 로컬 파일 정렬

페이지 영상과 로컬 파일의 첫 프레임 시각은 다를 수 있습니다.

1. 쉽게 식별되는 말이나 장면을 페이지에서 찾습니다.
2. 로컬 파일에서 같은 장면을 찾습니다.
3. `로컬 파일 시각 - 페이지 시각`을 초 단위로 입력합니다.
4. 여러 컷의 시작을 재생해 같은 오프셋이 맞는지 확인합니다.

예를 들어 페이지 10.000초의 장면이 파일 12.350초에 있으면 오프셋은
`2.350`입니다. 다른 원본 파일을 연결했다면 기존 체크포인트를 재사용하지
말고 정렬부터 다시 확인하세요.

## AudSeg 빈 타이밍

AudSeg는 선택한 컷의 오디오를 16kHz mono PCM으로 읽고 현재 브라우저 탭에서
활동 구간을 계산합니다.

```text
활성 컷 오디오
→ 20ms RMS frame과 적응형 소음 바닥
→ hysteresis·debounce·padding·merge
→ 조용한 골짜기 우선 분할
→ 최대 4초 빈 cue
→ 사람 전사와 검수
```

중요한 의미:

- 빈 cue는 오류가 아니라 의도된 결과입니다.
- 음악, 효과음, 박수와 키보드 소리도 활동으로 잡힐 수 있습니다.
- 조용한 발화는 놓칠 수 있습니다.
- 텍스트, 언어와 화자를 추측하지 않습니다.
- 모든 cue는 `reviewRequired` 상태로 시작합니다.
- 사람이 입력한 자막과 사람이 수정한 cue를 재실행으로 덮어쓰지 않습니다.

AudSeg는 프로젝트의 활성 컷을 한 컷씩 처리하고 컷마다 결과와 재개 정보를
저장합니다. 컷 하나의 상한은 30분, 16kHz mono Float32 PCM 128MiB이며 한
실행에서 새 cue는 최대 10,000개입니다. 취소하면 아직 시작하지 않은 컷을
처리하지 않습니다.

동일한 원본, 컷 범위와 알고리즘 지문이 맞는 완료 컷만 재개할 때 건너뜁니다.
원본이나 범위가 바뀌면 낡은 결과를 조용히 재사용하지 않습니다.

## 자막 편집

자막 레인은 기본 2개이며 `+`로 늘릴 수 있습니다. 같은 시각의 여러 화자를
서로 다른 레인에 둘 수 있습니다.

- 자막 트랙 우클릭: 현재 위치에 빈 자막 추가
- 자막 블록 우클릭: 해당 자막 삭제
- 블록 양끝 손잡이: 표시 시작·끝 변경
- 블록 본문 드래그: 시간 범위 이동
- 영상 위 자막 드래그: 화면 위치 변경
- 선택 자막 패널: 글, 색, 크기, 위치와 정밀 시각 입력

색상 레지스터는 고정 흰색 `#FFFFFF`와 최근 사용한 비흰색 5개를 기억합니다.
화자별 색을 정한 뒤 같은 화자에 일관되게 적용하세요.

기본 자막 스타일은 배경 없는 한 줄, 아래 중앙 `x=0.5`, `y=0.84`,
Pretendard ExtraBold입니다. Paperlogy ExtraBold도 선택할 수 있습니다.
자막 한 개는 최대 4초를 유지하고 문장 끝의 불필요한 `.`은 제거하되 `?`,
`!`, `…`, `~`는 보존하는 편집 규칙을 권장합니다.

## 이미지 에셋

웹에서 이미지 자체를 복사한 뒤 편집기에서 `Ctrl/Cmd+V`를 누르면 현재
재생 위치에 들어갑니다. 파일 선택과 붙여넣기 버튼도 사용할 수 있습니다.

- PNG와 WebP의 투명 영역을 보존합니다.
- 위치, 크기, 불투명도와 표시 시간을 조절할 수 있습니다.
- GIF는 정지 프레임으로 사용합니다.
- 원격 URL 문자열과 SVG는 직접 가져오지 않습니다.
- 동시에 표시되는 이미지의 실제 RGBA 메모리 상한은 256MiB입니다.

타임라인 **자석**은 자막과 이미지 경계를 가까이 끌었을 때 같은 컷의 반대
종류 경계에 붙입니다. 드래그 중 `Alt`를 누르면 잠시 끌 수 있습니다. 양끝을
완전히 같게 만들려면 **선택 에셋 구간에 정확히 맞춤** 또는 **선택 자막
구간에 정확히 맞춤**을 사용합니다.

## 구간별 음성

음성 트랙은 고정 1개입니다. 현재 위치에서 음성 설정 구간을 만들고 다음을
조절할 수 있습니다.

- 구간 음량
- 완전 음소거
- 페이드 인·아웃
- 시작·끝

짧은 단어를 가릴 때는 파형만 믿지 말고 앞뒤 음소까지 반복 재생해 확인하세요.
음원 분리, 다중 오디오 트랙과 플러그인 효과는 제공하지 않습니다.

## 임시저장과 복구

- **지금 임시저장**으로 즉시 스냅샷 생성
- 5분마다 자동 임시저장
- 프로젝트별 최근 5개 유지
- 복구본을 불러오기 직전 현재 상태 자동 저장
- 사이드패널의 **이 기기의 최근 편집 → 계속 편집**으로 현재본 열기
- **복구본 선택**으로 최근 저장 목록 열기

프로젝트, 이미지 Blob, 파일 핸들과 임시저장은 현재 브라우저 프로필에
보관됩니다. Extension 데이터를 지우거나 제거하면 사라질 수 있으므로 중요한
작업은 프로젝트 JSON도 내보내세요.

## 영상 내보내기

**영상 내보내기**에서 폴더를 선택하면 다음을 저장합니다.

- 편집 영상 MP4 또는 WebM
- 프로젝트 JSON
- 실제 글이 있는 자막의 SRT

빈 AudSeg cue는 타임라인과 프로젝트에는 남을 수 있지만 SRT에 가짜 문구로
출력되지 않습니다. 내보내기 전에 모든 빈 cue가 의도적인지 확인하세요.

출력은 가능한 경우 H.264/AAC MP4, 그렇지 않으면 VP9/Opus WebM입니다. 최대
1920×1080, 최대 60fps이며 VFR 입력은 컷 경계를 보존하는 CFR 출력으로
바뀝니다. 브라우저가 폴더 저장을 지원하지 않으면 파일별 다운로드로
전환될 수 있습니다.

## 로컬 데이터와 네트워크

- 원본 영상, 추출 오디오, 이미지와 최종 렌더는 이 기기 밖으로 보내지 않습니다.
- AudSeg 계산은 현재 브라우저 탭 안에서 끝납니다.
- 자막용 원격 호스트 권한이나 비밀 키 입력이 없습니다.
- 프로젝트와 복구본은 현재 브라우저 프로필에 보관됩니다.
- 다른 영상 회차의 컷이 섞이지 않도록 플랫폼·영상 ID·방송 시작 시각을
  비교합니다.
- 여러 창의 사이드패널은 revision을 확인해 최근 상태를 동기화합니다.

Extension은 열린 지원 영상 탭 연결, 로컬 저장, 사용자가 누른 순간의
클립보드 이미지 읽기와 치지직·YouTube 영상 식별에 필요한 권한만 사용합니다.
일반 텍스트 클립보드 기록을 저장하지 않습니다.

## 개발과 검증

기본 검증:

```bash
npm run check
git diff --check
```

Chromium, ChromeDriver, FFmpeg와 ffprobe가 있는 환경에서는 브라우저 상호작용과
실제 렌더까지 확인합니다.

```bash
npm run check:full
```

릴리스 파일은 전체 검증 뒤 고정 allowlist로 묶고 SHA-256을 기록합니다.

```bash
npm run package
```

개발 중 편집기만 안전하게 다시 읽으려면 다음을 사용합니다.

```bash
npm run dev:editor
```

## 알려진 제한

- AudSeg는 전사기가 아니며 발화와 음악·효과음을 구분하지 않습니다.
- 원본 코덱을 브라우저가 디코딩하지 못하면 미리보기와 렌더가 실패할 수 있습니다.
- 주 영상 트랙과 주 오디오 트랙만 사용합니다.
- 자막이 하나도 없으면 SRT를 만들지 않습니다.
- 공개 가능 여부, 음원, 수익화와 제3자 권리는 자동 승인하지 않습니다.
- 게시 전에 방송인·출연자·게임·음원·이미지 정책을 사람이 확인해야 합니다.
