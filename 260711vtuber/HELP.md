# 치지직·YouTube 키리누키 스튜디오 도움말

이 Extension은 치지직 라이브·VOD와 YouTube VOD에서 사람이 직접 고른 구간을
로컬 편집기로 옮겨 컷, 이미지, 음성과 한국어 자막을 다듬고 영상으로
내보냅니다. 원본 다운로드나 접근 제한 우회 기능은 없습니다.

자막 초벌은 AudSeg만 제공합니다. AudSeg는 소리가 활동하는 시간대를 찾아
빈 자막 블록을 만들며, 말의 내용을 받아쓰지 않습니다. 모든 블록은 원음을
들으며 사람이 직접 채우는 검수용 자리입니다.

## 처음 실행

Node.js 20.9 이상에서 가장 간단한 시작 방법:

```bash
./setup.sh
./kirinuki.sh start "https://chzzk.naver.com/video/..."
```

일반 Google Chrome을 쓰거나 명령을 직접 실행하려면:

```bash
npm ci --ignore-scripts
npm run build
npm run validate
```

Chrome 또는 Chromium 120 이상에서:

1. `chrome://extensions`를 엽니다.
2. **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다**를 누릅니다.
4. `260711vtuber/extension` 폴더를 선택합니다.
5. 지원 영상 탭을 열고 확장 아이콘을 눌러 사이드패널을 엽니다.

기존에 열려 있던 탭이 연결되지 않으면 그 영상 탭만 한 번 새로고침하세요.

## 좌표 찍기

1. 사용할 장면의 시작에서 **시작 스탬프 → 지금**을 누릅니다.
2. 장면의 끝에서 **끝 스탬프 → 지금**을 누릅니다.
3. 필요하면 메모를 적습니다.
4. **구간 저장**을 누릅니다.
5. 필요한 장면마다 반복합니다.
6. 목록에서 시작·끝·순서가 맞는지 확인합니다.
7. **통합 편집기에서 열기**를 누릅니다.

저장된 시작·끝은 사용자 확정 경계입니다. 자동 로직이 경계를 늘리거나
줄이지 않습니다. 겹친 구간도 임의로 합치거나 지우지 않습니다.

### 소스가 잡히지 않을 때

- 지원 영상이 최상위 탭에 열렸는지 확인합니다.
- YouTube 광고가 끝난 뒤 다시 시도합니다.
- 영상 탭을 한 번 새로고침합니다.
- 치지직 라이브와 VOD, 서로 다른 YouTube 영상이 같은 프로젝트에 섞이지
  않았는지 확인합니다.

## 편집기에서 원본 연결

편집기는 페이지 영상을 직접 가져오지 않습니다. 본인이 소유하거나 편집
권한을 받은 같은 영상의 로컬 파일을 선택해야 합니다.

1. **원본 연결**을 누릅니다.
2. 권한 있는 로컬 영상 하나를 선택합니다.
3. 파일 이름, 길이와 첫 장면이 예상한 원본인지 확인합니다.
4. 각 컷의 시작을 짧게 재생합니다.

파일 권한만 만료됐다면 프로젝트를 초기화하지 말고 같은 파일을 다시
선택하세요.

### 페이지 시각과 파일 시각이 다를 때

1. 페이지에서 쉽게 구분되는 말이나 장면을 찾습니다.
2. 로컬 파일에서 같은 지점을 찾습니다.
3. `로컬 파일 시각 - 페이지 시각` 값을 초 단위로 입력합니다.
4. **적용**을 누릅니다.
5. 앞·중간·뒤 컷을 각각 재생해 오프셋이 일정한지 확인합니다.

페이지 10.000초의 장면이 파일 12.350초에 있으면 `2.350`을 입력합니다.

## 컷 편집

### 양끝 줄이기

영상 트랙의 컷 블록 왼쪽 또는 오른쪽 손잡이를 끌어 경계를 바꿉니다. 정밀한
값은 선택 컷 패널에서 직접 입력할 수 있습니다.

### 가운데 구간 삭제

1. 삭제할 부분의 시작에 재생헤드를 둡니다.
2. **시작 I**를 누릅니다.
3. 삭제 끝으로 이동합니다.
4. **끝 O**를 누릅니다.
5. 표시된 범위를 확인합니다.
6. **구간 삭제**를 누릅니다.

삭제된 길이만큼 뒤 영상, 이미지, 음성 설정과 자막이 함께 당겨집니다. 삭제
범위와 겹친 항목은 남은 영상에 맞게 잘리거나 분할됩니다.

### 컷 순서 바꾸기

하나 이상의 컷을 체크한 뒤 그룹 이동 버튼이나 `Alt+↑`, `Alt+↓`를 사용합니다.
선택한 컷들의 상대 순서는 유지됩니다.

## AudSeg 빈 자막 타이밍

편집기에서 **활성 컷 전체 초벌 만들기**를 누릅니다.

AudSeg가 하는 일:

- 선택 컷의 오디오 활동 구간을 찾습니다.
- 긴 활동은 조용한 지점을 우선해 최대 4초로 나눕니다.
- 타임라인에 빈 자막 블록을 만듭니다.
- 같은 입력과 설정에서는 재현 가능한 결과를 만듭니다.
- 컷 하나가 끝날 때마다 결과와 재개 정보를 저장합니다.

AudSeg가 하지 않는 일:

- 말을 글로 바꾸지 않습니다.
- 화자와 언어를 판정하지 않습니다.
- 음악과 발화를 구분하지 않습니다.
- 빈 블록을 게시 가능한 자막으로 표시하지 않습니다.
- 사람이 만든 자막이나 사람이 고친 블록을 덮어쓰지 않습니다.

음악, 효과음, 박수와 키보드 소리에도 블록이 생길 수 있습니다. 필요 없는
블록은 지우고, 놓친 조용한 발화는 자막 트랙을 우클릭해 직접 추가하세요.

컷 하나는 최대 30분, 분석용 Float32 PCM은 최대 128MiB입니다. 한 실행에서
새 블록은 최대 10,000개입니다. 긴 프로젝트는 컷을 적당히 나누는 편이
검수하기 쉽습니다.

## 자막 직접 입력

자막 레인은 기본 2개입니다. 같은 시각에 여러 사람이 말하면 다른 레인에
각각 둘 수 있고 `+`로 레인을 늘릴 수 있습니다.

### 만들기와 지우기

- 자막 트랙 빈 곳 우클릭: 현재 위치에 새 자막
- 자막 블록 우클릭: 해당 자막 삭제
- 자막 블록 클릭: 선택 자막 패널 열기

### 시간 바꾸기

- 블록 왼쪽 손잡이: 시작 시각
- 블록 오른쪽 손잡이: 끝 시각
- 두 손잡이 사이 본문: 길이를 유지한 채 이동
- 선택 자막 패널의 숫자 입력: 정밀 시각

한 자막은 4초 이하를 권장합니다. 여러 문장이 길게 이어지면 읽기 좋은
호흡으로 나누세요.

### 글과 문장부호

- 원문의 말투와 의미를 보존합니다.
- 들리지 않는 고유명사를 추측하지 않습니다.
- 문장 끝의 불필요한 `.`은 보통 넣지 않습니다.
- `?`, `!`, `…`, `~`는 의미가 있으면 유지합니다.
- 빈 AudSeg 블록은 실제 글을 채우거나 의도적으로 삭제합니다.

### 위치와 색

기본 위치는 아래 중앙 `x=0.5`, `y=0.84`입니다. 영상 위 자막을 직접 끌거나
선택 자막 패널의 위치 조절을 사용합니다.

색상 선택기 오른쪽 레지스터:

- 흰색 `#FFFFFF` 고정
- 최근 사용한 비흰색 5개
- 색 버튼 클릭 시 선택 자막에 즉시 적용

주 화자는 흰색을 기본으로 두고 식별 가능한 다른 화자는 서로 다른 색을
일관되게 쓰는 편이 좋습니다.

기본 글꼴은 Pretendard ExtraBold이며 Paperlogy ExtraBold도 선택할 수 있습니다.
두 글꼴은 배포물에 각각의 OFL 원문과 함께 포함됩니다.

## 이미지 에셋

웹에서 이미지 자체를 복사한 뒤 편집기에서 `Ctrl/Cmd+V`를 누르거나 에셋
패널의 붙여넣기·파일 선택을 사용합니다.

- PNG·JPEG·WebP·GIF를 받습니다.
- PNG와 WebP의 투명 영역을 보존합니다.
- GIF는 정지 프레임으로 사용합니다.
- 위치, 크기, 불투명도와 시작·끝을 조절할 수 있습니다.
- SVG와 원격 URL 문자열은 받지 않습니다.

붙여넣은 이미지 Blob은 프로젝트와 함께 현재 브라우저 프로필에 저장됩니다.

### 자막과 이미지 시간 맞추기

타임라인 **자석**이 켜져 있으면 자막 또는 이미지 경계를 반대 종류 경계
가까이 끌었을 때 가이드가 나타나며 붙습니다. 드래그 중 `Alt`를 누르면 그
동작에서만 자석을 끕니다.

양끝을 완전히 같게 하려면 같은 컷의 자막과 이미지를 선택한 뒤:

- **선택 에셋 구간에 정확히 맞춤**
- **선택 자막 구간에 정확히 맞춤**

중 하나를 누릅니다.

## 구간별 음성

음성 레인은 1개입니다. 음성 트랙을 우클릭하거나 현재 위치 추가 버튼을
눌러 설정 구간을 만듭니다.

- 음량
- 완전 음소거
- 페이드 인
- 페이드 아웃
- 시작·끝

짧은 단어 음소거는 파형만 보지 말고 반복 재생하며 앞뒤 발음까지 확인하세요.

## 임시저장과 닫은 작업 복구

- **지금 임시저장**: 즉시 스냅샷 생성
- 5분마다 자동 임시저장
- 프로젝트별 최근 5개 유지
- 복구본을 불러오기 직전 현재 상태 자동 저장

닫은 작업을 다시 열려면:

1. 같은 브라우저 프로필에서 사이드패널을 엽니다.
2. **이 기기의 최근 편집**을 찾습니다.
3. 현재본은 **계속 편집**으로 엽니다.
4. 이전 스냅샷은 **복구본 선택**으로 고릅니다.

중요한 작업은 프로젝트 JSON도 내보내세요. Extension 데이터나 해당 브라우저
프로필을 지우면 복구본과 이미지가 사라질 수 있습니다.

## 내보내기

**영상 내보내기**에서 폴더를 고르면 다음이 저장됩니다.

- MP4 또는 WebM 영상
- 프로젝트 JSON
- 실제 글이 있는 자막의 SRT

같은 이름이 있으면 새 이름을 제안합니다. 폴더 저장을 지원하지 않는
브라우저에서는 파일별 다운로드로 바뀔 수 있습니다.

내보내기 전 확인:

- 모든 컷 시작·끝과 순서
- 가운데 삭제 뒤 전체 싱크
- 빈 AudSeg 블록의 입력 또는 삭제
- 자막 글·시각·화자 색·위치
- 이미지 투명도와 표시 시간
- 짧은 음소거 경계
- 방송인·출연자·음원·이미지 정책

## 문제 해결

### AudSeg 블록이 너무 많음

음악과 효과음도 활동으로 감지되는 것이 정상입니다. 필요 없는 블록을
삭제하세요.

### AudSeg 블록에 글이 없음

정상 동작입니다. AudSeg는 시간 틀만 만들며 글은 사람이 입력합니다.

### 조용한 말의 블록이 없음

자막 트랙 빈 곳을 우클릭해 직접 블록을 추가하고 시작·끝을 맞추세요.

### 자막 손잡이를 잡기 어려움

타임라인을 확대하고 블록 양끝 손잡이를 잡으세요. 정밀 값은 선택 자막
패널에서 직접 입력할 수 있습니다.

### 원본 싱크가 맞지 않음

페이지 시각과 로컬 파일의 정렬 오프셋을 다시 확인합니다. 다른 인코딩 파일을
연결했다면 파일의 실제 시작 지점과 길이도 비교하세요.

### 저장된 원본을 다시 열 수 없음

파일 권한이 만료된 것입니다. 프로젝트는 그대로 두고 **원본 연결**에서 같은
파일을 다시 선택합니다.

### 내보내기가 느리거나 메모리가 부족함

다른 무거운 앱을 닫고 프로젝트를 더 작은 컷 묶음으로 나눕니다. 긴 원본
전체를 한 번에 복사하지는 않지만 영상 인코딩에는 프레임 버퍼가 필요합니다.
