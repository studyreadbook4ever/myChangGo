## 수학 모형

### 일반 2변수 선형계획

공개 교과서의 첫 계산기는 다음 형태의 자원배분 문제를 풉니다.

```text
maximize    c₁x + c₂y
subject to  a₁x + b₁y ≤ r₁
            a₂x + b₂y ≤ r₂
            x, y ≥ 0
```

브라우저는 축 절편과 제약선 교점을 열거하고, 실행가능성을 검사한 뒤, 모든
꼭짓점의 목적값을 비교합니다. 그래프와 같은 숫자를 결과 카드에도 써서 시각자료가
유일한 설명이 되지 않게 했습니다.

### 제약의 차분 한계가치

선택한 자원 한도를 `Δ`만큼 늘린 뒤 문제를 다시 풀어 다음 값을 보여 줍니다.

```text
[V(b + Δ) - V(b)] / Δ
```

이는 선택한 구간의 유한차분입니다. 작은 범위에서 최적기저가 유지될 때 LP
쌍대변수의 그림자가격과 대응하지만, 병목이 바뀌거나 정수성이 들어오면 영구적인
시장가격처럼 해석할 수 없습니다.

### 불확실성 아래 선택

세 대안에 대해 다음 기준을 나란히 계산합니다.

- 확률을 받아들이는 **기대값 최대**
- 가장 나쁜 시나리오를 비교하는 **최악값 최대**
- 각 시나리오의 사후 최선과의 차이를 줄이는 **최대후회 최소**

세 기준이 서로 다른 답을 낼 수 있다는 사실 자체가 학습 목표입니다. 확률과
손실함수는 계산기가 만들어 주는 사실이 아니라 결정자가 공개해야 할 가정입니다.

### AI 접근비용

구독료를 다음 네 장부로 분리합니다.

- 사용자 소득 대비 가격 부담
- 사용자가 가정한 절약시간과 시간가치
- 공급자의 제공원가
- 사회 전체의 접근성과 분배

공개 계산기는 앞의 두 장부만 계산합니다. 사용자에게 큰 편익이 있다는 사실로
공급원가나 공정성을 추론하지 않으며, 정가 환산액을 원가로 취급하지 않습니다.

## 역사와 이론의 경계

- 칸토로비치는 1938년 합판 생산의 원료·설비 배분 문제에서 출발했고, 1939년
  선형 목적과 제약 아래 활동 강도를 고르는 방법을 발표했습니다.
- 조지 단치그는 1947년 심플렉스법을 독립적으로 발전시켰습니다. 당시
  `programming`은 컴퓨터 코딩보다 계획 수립이라는 뜻에 가까웠습니다.
- 칸토로비치의 해결승수, 코프만스의 효율가격, 현대 LP의 쌍대변수·그림자가격은
  같은 계열의 희소성 언어입니다.
- 주어진 모형을 푸는 계산 문제, 현실의 분산된 정보를 얻는 문제, 사람들이
  정직하게 보고할 유인, 목적함수의 정당성은 서로 다른 층입니다.
- 선형계획이 가능하다는 사실은 중앙계획·시장·기업 내부 배분 중 어느 제도가
  언제 정당하고 우월한지를 단독으로 판결하지 않습니다.

## AI 연구를 읽는 방법

서지는 자료마다 다음 증거 표지를 붙입니다.

- `1차 역사자료`
- `공식 해설`
- `동료심사`
- `워킹페이퍼`
- `프리프린트`
- `교육자료`

생성형 AI 생산성 연구는 과업, 표본, 숙련도, 검증비용과 관측기간에 따라 결과가
달라집니다. 단기 글쓰기·고객지원·신규 코딩 과제의 향상을 거시 총요소생산성이나
장기 고용효과로 곧장 확대하지 않습니다. 반대로 특정 숙련 개발자 실험의 속도
저하도 모든 AI 활용의 무효를 뜻하지 않습니다.


## 검증

```bash
npm run verify
```

`verify`는 다음을 모두 검사합니다.

1. 모든 JavaScript 파일의 문법
2. 회귀·교란·정수배분·LP·차분 그림자가격·불확실성·접근비용 수학 테스트
3. 정확히 8부·40강·12사례·80용어인지와 콘텐츠 최소 깊이
4. 모든 강의 출처 ID가 실제 서지에 연결되는지
5. 공개 교과서의 검색·펼침·진행 저장·4개 계산기·사례 필터·사전·캡스톤
6. 계산 실험실의 10개 동선과 8/8 전이 검표
7. 데스크톱과 390px 모바일의 가로 넘침·터치 목표·런타임 오류
8. 외부 리소스 요청, 중복 ID, 깨진 내부 앵커, 손상 저장값 복구

실제 Chromium을 사용합니다. 경로가 표준 위치가 아니라면 `CHROMIUM_PATH`를
지정할 수 있습니다.
