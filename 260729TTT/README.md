# [선택의 박물관 · 260729TTT](https://studyreadbook4ever.github.io/myChangGo/260729TTT/)

> **TTT means Thanks To Tibo.**

중학생도 한 바퀴 직접 움직이며 미래 AI 기반 계량경제학과 칸토로비치의
자원배분 이론을 이해하도록 만든 웹 체험관입니다.

<https://studyreadbook4ever.github.io/myChangGo/260729TTT/>

## 한 문장으로

계량경제학은 현실의 데이터에서 효과를 배우고, 칸토로비치식 최적화는 그
효과를 바탕으로 부족한 자원을 배분하며, AI 에이전트는 두 과정을 빠르게
반복하되 사람은 목표·가정·승인권을 쥡니다.

## 설명 깊이

기본값인 **차근차근 모드(약 25분)**에서는 모든 방이 같은 학습 사다리를
사용합니다.

1. 낯선 말의 뜻을 일상어로 풉니다.
2. 생활 비유와 실제 숫자를 한 단계씩 따라갑니다.
3. 흔한 오해와 이 모형이 말할 수 없는 범위를 구분합니다.
4. 모든 방의 `내 말로 확인` 질문과 전시 사이의
   `방금 안 것 → 아직 모르는 것 → 다음 방` 다리로 연결합니다.

**핵심만 모드(약 12분)**를 고르면 체험과 한 줄 설명은 유지한 채 긴 해설 카드만
접힙니다. 언제든 각 카드를 다시 펼칠 수 있습니다. 출구에는 15개 핵심 용어
사전과 새로운 대피소 사례의 8문항 전이 검표가 있습니다.

## 한 바퀴 동선

1. **축제 전날** — 계산보다 먼저 무엇을 성공이라 부를지 고릅니다.
2. **부족함의 창고** — 8개의 작업칸을 이해·검증·체험에 직접 나눕니다.
3. **조합의 정원** — 가능한 조합을 비교해 칸토로비치식 최적화를 만납니다.
4. **보이지 않는 가격표** — 고전적 그림자가격에 대응하는 다음 한 칸의 이산 한계가치를 확인합니다.
5. **데이터의 거울** — 상관관계가 교란요인 때문에 인과처럼 보이는 과정을 봅니다.
6. **평행세계 실험실** — 반사실과 비교집단, 무작위 배정의 이유를 체험합니다.
7. **AI 측정실** — AI가 만든 변수의 측정오차를 사람 표본 감사로 고칩니다.
8. **함께 운전하는 조종실** — 근거·가정·불확실성·되돌리기를 확인하고 에이전트 제안을 승인합니다.
9. **제로토큰 공방과 출구** — 반복 판단의 도구화와 새 상황으로의 개념 전이를 확인합니다.

모든 전시는 미래학교 축제를 준비한다는 한 이야기로 이어집니다. 마지막에는
재난대피소라는 새로운 사례의 8문제를 모두 해결해야 `한 바퀴 이해 완료`
도장이 열립니다.

## TT 도슨트와 Agent in the Loop

`TT · Thinking Together`는 자유대화를 흉내 내는 실시간 AI가 아닙니다. 현재
관람객의 목표, 배분, 실험, 감사, 승인 상태를 읽고 다음 질문을 고르는
**로컬 상태기계형 에이전트 시뮬레이션**입니다.

제안 실행 전에는 항상 다음 네 질문을 사람이 확인합니다.

1. 왜 이 제안인가?
2. 어떤 근거와 가정에 기대는가?
3. 얼마나 불확실한가?
4. 틀리면 멈추거나 되돌릴 수 있는가?

외부 모델 API, 로그인, 분석 도구, 사용자 입력 전송은 없습니다. 진행 상태와
마지막 한 문장은 현재 브라우저의 `localStorage`에만 저장됩니다.

## 수학 모형의 정직한 경계

- 배분 점수와 학생 자료는 개념 설명을 위한 **결정론적 가상 데이터**입니다.
- 배분 모형은 정수 단위 한계효과를 전수 비교하며 기본 8칸에서
  `이해 3 · 검증 3 · 체험 2 = 109점`을 반환합니다.
- 고전적 그림자가격은 연속 선형계획법의 제약을 조금 풀 때 생기는 국소 가치입니다.
  이 정수 전시는 그 생각에 대응하는 `V(B+1)-V(B)`를 이산 한계가치로 보여주며,
  실제 시장가격이 아닙니다.
- 준비도를 통제한 회귀는 이 장난감 세계에서 심어 둔 효과를 정확히 되찾지만,
  현실에서 관찰변수를 통제했다는 사실만으로 인과관계가 증명되지는 않습니다.
- Zero Token Architecture는 정립된 학술 이론명이 아니라 AI 과잉 적용을 비튼
  설계 철학입니다. 여기서는 검증된 반복작업의
  **런타임 대규모 언어모델(LLM) 호출이 0**이라는 뜻이며 개발·검증·일반 계산
  비용이 0이라는 뜻이 아닙니다.

각 모형의 구현과 경계조건은 [`src/model.js`](src/model.js), 회귀·교란·최적화·
이산 한계가치·손익분기 검증은 [`tests/model.test.js`](tests/model.test.js)에
있습니다.

## 로컬에서 관람

Node.js 20 이상에서 별도 패키지 설치 없이 실행됩니다.

```bash
npm run dev
```

그다음 <http://127.0.0.1:4173>을 엽니다.

## 검증

```bash
npm run verify
```

`verify`는 JavaScript 문법 검사, Node 내장 테스트 러너의 수학 모형 테스트,
실제 Chromium에서의 전체 관람 루프를 실행합니다. 브라우저 검사는 최적화부터
8/8 출구 검표까지 직접 조작하고 데스크톱·390px 모바일의 가로 넘침과 핵심
터치 목표 크기, 런타임 오류, 외부 리소스 요청 여부를 확인합니다.

Chromium 경로가 표준 위치가 아니라면 `CHROMIUM_PATH`로 지정할 수 있습니다.
