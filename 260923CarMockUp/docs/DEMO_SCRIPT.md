# DriveMate 발표 가이드

권장 화면: PC 1920×1080, 브라우저 확대 100%. 우측 상단 **발표 모드**를 켜면 지도와 추천, 시연 컨트롤을 한 화면에 보여줍니다. 폰에서는 하단 메뉴로 캘린더·차량·주행 기록을 확인할 수 있습니다.

기본 데모 데이터로 시작하려면 화면 아래 **데모 데이터 초기화**를 선택합니다. 전체 시연을 다시 시작하면 새 주행 한 건이 저장됩니다. 장면을 뒤로 돌려 같은 도착을 다시 눌러도 중복 저장하지 않습니다.

| 구간 | 조작 | 발표 멘트 예시 |
| --- | --- | --- |
| 자체 캘린더 | 캘린더를 연다 | “DriveMate 안에서 일정을 직접 관리합니다. 목적지뿐 아니라 몇 분 먼저 도착하고 싶은지도 개인화 정보입니다.” |
| 출발 추천 | 드라이브 → 발표 모드 → 전체 시연 | “18시 30분 미팅입니다. 기본 주행 12분에 제 운전 패턴 3분, 주차 5분, 도보 3분, 여유 7분을 더해 18시 출발을 권합니다.” |
| 이동 | 자동으로 차량이 이동한다 | “이 작은 가상 도시는 약 5km 규모의 시연 공간입니다.” |
| 돌발 정체 | 자동으로 03 장면 전환 | “12분의 정체로 도착이 18시 35분으로 늦어집니다. 일정에 5분 늦는다는 영향을 함께 보여줍니다.” |
| 경로 변경 | 자동으로 04 장면 전환 | “대체 경로로 9분을 줄이면 18시 26분, 약속까지 4분이 남습니다. 지도와 판단 근거가 함께 바뀝니다.” |
| 도착 | 자동으로 05 장면 전환 | “차량 주행거리에 3.8km가 더해지고 주차 위치를 기억합니다.” |
| 기록·정비 | 주행 기록 / 내 차량 | “돌발 정체는 평소 운전 패턴에서 제외합니다. 다음 점검은 자체 캘린더의 빈 시간에 넣을 수 있습니다.” |

질의응답용으로는 다음 조작이 좋습니다.

- **개인화가 실제로 연결되는가?** 캘린더의 미팅을 수정해 도착 여유를 7분에서 10분으로 변경하고 경로를 봅니다. 권장 출발은 18:00에서 17:57로 바뀝니다.
- **일정이 겹치면?** 토요일 10시를 일정으로 채우고 차량 탭에서 정비 추천을 확인합니다. 해당 시간과 겹치지 않는 후보를 선택합니다.
- **외부 API가 필요한가?** 이번 결과물은 지도·주행·추천 문장을 모두 로컬 시나리오로 표현한 목업입니다. 실제 서비스 연동은 다음 단계입니다.

자동 시연은 1배속 약 40초이며 2배속, 일시정지·재개, 장면별 직접 이동을 지원합니다. 영상은 무음이므로 위 멘트를 발표자가 직접 설명하거나 편집 프로그램에서 내레이션을 추가할 수 있습니다.
