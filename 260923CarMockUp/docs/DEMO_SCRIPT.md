# DriveMate 발표 가이드 · 1.1.0

PC와 안드로이드 폰에서 같은 흐름으로 진행합니다. 첫 화면은 일정과 추천을 살펴보는 대시보드이며, **주행 시작**을 누르면 방향 안내와 도착 정보가 있는 전체 화면 내비게이션으로 전환됩니다. 메뉴와 캘린더는 주행을 마친 뒤 다시 사용할 수 있습니다.

기본 데이터로 시작하려면 대시보드 맨 아래 **데모 데이터 초기화**를 선택합니다. 목적지에 도착한 이동은 한 번만 저장되며, 도중에 안내를 종료한 이동은 완료 기록에 추가되지 않습니다.

| ----------- | -------------------------------------- | -------------------------------------------------------------------------------------------------------------------- |
| 자체 캘린더 | 캘린더를 연다                          | “DriveMate 안에서 일정을 직접 관리합니다. 목적지뿐 아니라 몇 분 먼저 도착하고 싶은지도 개인화 정보입니다.”           |
| 출발 추천   | 드라이브로 돌아온다                    | “18시 30분 미팅입니다. 기본 주행 12분에 제 운전 패턴 3분, 주차 5분, 도보 3분, 여유 7분을 더해 18시 출발을 권합니다.” |
| 주행 시작   | **주행 시작**을 누른다                 | “출발하면 화면 전체가 내비게이션으로 바뀝니다. 지도와 진행 방향, 남은 거리와 도착 예정에 집중합니다.”                |

| 경로 선택   | **우회 경로로 변경**을 누른다          | “대체 경로로 9분을 줄이면 약속 장소에 18시 26분, 약속보다 4분 먼저 도착합니다. 경로와 도착 예상도 함께 바뀝니다.”    |

| 기록·정비   | 주행 기록 / 내 차량을 연다             | “돌발 정체는 평소 운전 패턴에서 제외합니다. 다음 점검은 자체 캘린더의 빈 시간에 넣을 수 있습니다.”                   |

다른 선택도 확인할 수 있습니다.

- **현재 경로 유지:** 정체 안내에서 이 버튼을 누르면 원래 경로로 계속 이동합니다. 기본 미팅의 경우 주행 27분, 거리 3.2km가 기록됩니다. 정체를 겪었으므로 이 기록도 평소 운전 패턴 계산에서 제외합니다.
- **안내 도중 종료:** **안내 종료** 또는 안드로이드 뒤로 가기를 누르면 확인 창이 나옵니다. **계속 안내**로 돌아가거나 **안내 종료하기**로 대시보드에 복귀할 수 있습니다. 완료하지 않은 이동은 저장하지 않습니다.
- **개인화 변경:** 캘린더의 미팅에서 도착 여유를 7분에서 10분으로 수정하고 경로를 봅니다. 권장 출발은 18:00에서 17:57로 바뀝니다.
- **일정 충돌:** 토요일 10시를 다른 일정으로 채우고 차량 탭에서 정비 추천을 확인합니다. 기존 일정과 겹치지 않는 후보를 선택합니다.

실제 이동 시간을 압축해 차량이 움직이는 목업입니다. 출발 후 정체 제안이 나타나며, 경로를 선택하면 목적지까지 안내가 이어집니다. 실제 GPS·교통·차량 센서·LLM은 연결하지 않습니다. 영상은 무음이며 발표자가 위 멘트를 직접 설명할 수 있습니다.
