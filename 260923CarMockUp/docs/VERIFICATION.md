# 검증 기록 · 1.1.0

검증일: 2026-09-23.

## 웹

- `npm run build`: TypeScript strict 검사 및 Vite 정적 빌드 통과.
- `npm test`: 8개 계산 테스트 통과. 출발 추천, 개인화 중앙값, 정체/우회 시간, 현재시각의 연속성, 정비 일정 충돌, 손상된 저장값 복구, 자정 경계, 현재 경로를 유지한 정체 기록의 개인화 제외.
- `npx playwright test --workers=2`: Chromium 10개 테스트 통과. 전체 실행 1.3분.
- 내비게이션: **주행 시작** 후 화면 전체 사용, 대시보드 메뉴 숨김, 이전 장면·재생 컨트롤 제거 확인. 차량 도착과 주차·도보 이후 약속 장소 도착을 구분해서 검증.
- 경로 선택: 우회 시 3.8km·18분, 현재 경로 유지 시 3.2km·27분 기록. 두 경로 모두 한 번만 저장되고, 돌발 정체가 평소 운전 보정값을 바꾸지 않음을 확인.
- 안내 종료: 종료 확인과 계속 안내, 도중 종료 시 거리·주차·주행 기록 미저장, Android 뒤로 가기 연결 확인.
- 캘린더: 일정 CRUD·새로고침 유지, 시간·목적지·여유 변경에 따른 출발 추천, 겹치지 않는 정비 시간 선택, 미래 일정 날짜, 모달 포커스와 Escape 확인.
- 저장값 복구와 일정이 없는 목적지 탐색에서 존재하지 않는 약속을 표시하지 않음을 확인.
- 모바일 390×844 및 가로 844×390에서 전체 화면 내비게이션과 가로 넘침 없음 확인. 데스크톱·모바일 화면은 별도 스크린샷으로도 확인.
- 지도: 8,008개 경로·진행률 조합의 방향 안내 상태와 차량 추적 카메라 좌표 검증. 정체·도착 카드 위에 차량이 보이도록 카메라 위치 조정.

브라우저 테스트의 긴 주행은 Playwright 가상 시간으로 진행하며, 실제 화면의 버튼을 통해 경로를 선택합니다. 자동 테스트는 가상 데이터와 화면 상태의 연결을 확인합니다. 실제 도로 안내의 정확성을 검증하는 테스트는 아닙니다.

## Android

Android SDK 35 / Java 21 / Gradle 8.10.2 환경에서 **1.1.0-demo / versionCode 2**의 `assembleDebug`, `lintDebug`를 통과했습니다. 최종 웹 에셋을 APK에 번들로 포함합니다.

API 35 / AOSP ATD x86_64 에뮬레이터와 Android System WebView 124.0.6367.219에서 확인한 항목:

- 비행기 모드와 Wi-Fi·모바일 데이터가 꺼진 상태에서 로컬 지도·한글 폰트·화면 작동.
- 기존 1.0.0 위에 `install -r`로 업데이트한 뒤 일정·주행 기록·차량 주행거리·주차 위치가 동일하게 유지됨.
- 세로 412×915에서 내비게이션이 WebView 전체를 채우고, 네이티브 전체 화면 진입 호출이 적용됨.
- Android 뒤로 가기로 안내 종료 확인, 취소 후 계속 안내, 도중 종료 시 데이터 변화 없음.
- 세로·가로 화면 전환과 주행 상태 유지.
- 정체 안내에서 우회 수락 후 도착 시 주행 기록이 6건에서 7건으로 한 번 증가하고, 주행거리가 9,843.8km에서 9,847.6km로 갱신되며 스튜디오 주차 위치 저장.
- **주행 마치기** 후 대시보드 복귀와 네이티브 전체 화면 모드 해제.
- 앱 강제 종료·재실행 뒤에도 일정·주행 기록·차량 상태가 동일하게 유지됨.
- JavaScript 런타임 오류 0건.
- 최종 APK의 서명 v2 검증, 요청 권한 0개, 번들 128개 파일과 최종 웹 빌드의 내용 일치.
- `docs/android.png`, `docs/android-navigation.png` 캡처와 화면 육안 확인.

배포 APK 크기는 4,862,711 bytes이며 SHA-256은 `441fac7d2bbc297737c412feabce951cbef24d31ad4fd46e35aa729ec32ec0ee`입니다.

실물 휴대폰은 이 작업 환경에 연결되어 있지 않습니다. 사용한 ATD 에뮬레이터 이미지에는 일반 휴대폰과 같은 시스템 바가 없어, 실제 시스템 바가 사라지는 모습은 실물에서 확인해야 합니다. 네이티브 전체 화면 전환 호출과 WebView 주행 화면은 에뮬레이터에서 확인할 수 있습니다.
