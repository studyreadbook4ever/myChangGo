## Clean-room implementation

The engine, demo, synthetic demo records, tests, and tooling were authored for
this project. No third-party implementation was translated, copied, vendored,
or generated from a third-party source tree.

efchSQL has:

- no runtime or development package dependencies;
- no bundled third-party source code;
- no copied production datasets;
- no bundled images, icons, fonts, audio, or video;
- no CDN, remote font, analytics, or remotely loaded application asset.

The demo uses system fonts and CSS-drawn interface elements. Its records are
fictional test fixtures, not scraped social-network content.
