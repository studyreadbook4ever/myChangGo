# 치지직·YouTube 키리누키 스튜디오 도움말

이 Extension은 치지직 라이브·VOD와 YouTube VOD에서 사용자가 직접 고른 구간을 로컬 편집기로 옮겨 컷, 이미지 에셋, 음성, 한국어 자막을 다듬고 영상으로 내보냅니다. 원본을 내려받거나 접근 제한을 우회하는 기능은 없습니다. 본인이 소유하거나 사용할 권한이 있는 로컬 원본을 연결해야 합니다.

## 빠른 시작

1. 저장소에서 `npm ci --ignore-scripts && npm run build`를 실행합니다.
2. Chromium의 `chrome://extensions`에서 개발자 모드를 켜고 `extension` 폴더를 불러옵니다.
3. 치지직 또는 YouTube 영상 탭에서 Extension 사이드패널을 엽니다.
4. 시작 시각에서 **시작 스탬프 → 지금**, 끝 시각에서 **끝 스탬프 → 지금**을 누릅니다.
5. **구간 저장**을 누르고 필요한 컷을 모두 반복합니다.
6. **통합 편집기에서 열기**를 누릅니다.
7. **원본 연결**에서 같은 영상의 로컬 파일을 선택합니다.
8. 자막 초벌 방식으로 **로컬 Whisper** 또는 **AudSeg**를 고릅니다.
9. **활성 컷 전체 초벌 만들기**를 누릅니다.
10. 자막과 컷을 원음에 맞춰 검수한 뒤 **영상 내보내기**를 누릅니다.

글까지 자동으로 받아 적고 싶으면 Whisper를 사용합니다. 자막 내용을 직접 쓰되 소리가 있는 구간의 타이밍 틀만 빨리 받고 싶으면 AudSeg를 사용합니다. 두 방식 모두 API 키가 필요 없고 인터넷 자막 서비스로 음성을 보내지 않습니다.

## 지원 소스

- 치지직 라이브
- 치지직 다시보기
- `youtube.com/watch`
- `youtu.be`
- YouTube Shorts
- 최상위 탭으로 연 YouTube embed

진행 중인 YouTube 라이브와 다른 사이트 안에 삽입된 iframe은 지원하지 않습니다. 광고 재생 중인 YouTube에서는 광고 시각이 프로젝트 좌표에 섞이지 않도록 캡처를 막습니다.

## 로컬 원본 준비

Extension은 영상 다운로드 기능을 제공하지 않습니다. 서비스의 공식 저장 기능이나 사용 권한이 확인된 별도 도구로 원본을 준비하세요.

YouTube에서 권한이 있는 영상을 `yt-dlp`로 준비하는 예시는 다음과 같습니다.

```bash
# 제공되는 최고 영상·음성 스트림을 우선 보존
yt-dlp -f "bv*+ba/b" --merge-output-format mkv "사용 권한이 있는 URL"

# Chromium 편집 호환성을 우선
yt-dlp -f "bv*[vcodec^=avc1]+ba[acodec^=mp4a]/b[ext=mp4]" \
  --merge-output-format mp4 "사용 권한이 있는 URL"
```

다운로드 가능 여부, 약관, 저작권과 게시 정책은 사용자가 확인해야 합니다.

## 사용자 확정 컷

사용자가 저장한 시작·끝은 확정 범위입니다.

- 자동 초벌은 재미있는 구간을 새로 고르지 않습니다.
- 경계를 자동으로 넓히거나 줄이지 않습니다.
- 컷 순서를 자동으로 바꾸지 않습니다.
- 겹치는 컷도 임의로 합치거나 버리지 않습니다.
- 편집기에서 사람이 손잡이를 끌거나 값을 입력했을 때만 경계가 바뀝니다.

여러 컷을 체크한 뒤 `Alt+↑`, `Alt+↓` 또는 그룹 이동 버튼으로 순서를 바꿀 수 있습니다.

### 영상 중간 구간 삭제

컷의 양끝만 줄이는 것이 아니라 타임라인 중간을 덜어내려면:

1. 삭제 시작점에 재생헤드를 둡니다.
2. **시작 I**를 누릅니다.
3. 삭제 끝점으로 이동합니다.
4. **끝 O**를 누릅니다.
5. 선택 범위를 확인하고 **구간 삭제**를 누릅니다.

삭제 뒤 뒤쪽 영상, 이미지 에셋, 음성 설정, 자막은 같은 시간만큼 앞으로 이동합니다. 삭제 구간과 겹친 항목은 남는 영상 구간에 맞춰 잘리거나 분할됩니다. 큰 삭제 전에는 **지금 임시저장**을 권장합니다.

## 페이지 시각과 로컬 원본 맞추기

같은 방송이라도 페이지 시각과 로컬 파일의 첫 프레임 시각이 다를 수 있습니다.

1. 페이지에서 쉽게 구분되는 말이나 장면의 시각을 확인합니다.
2. 로컬 원본에서 같은 지점을 찾습니다.
3. `로컬 원본 시각 - 페이지 시각`을 **페이지 시각 ↔ 로컬 원본 정렬**에 초 단위로 입력합니다.
4. **적용**을 누르고 컷 시작점을 몇 곳 재생해 확인합니다.

예를 들어 페이지 10.000초의 장면이 로컬 파일 12.350초에 있다면 오프셋은 `2.350`입니다.

## 자막 초벌 방식

편집기에는 정확히 두 가지 방식이 있습니다.

### 로컬 Whisper: 글과 타이밍

Whisper는 선택 컷의 16kHz mono PCM을 이 기기의 loopback companion으로 보내 한국어 timed transcript를 만듭니다.

- 기본 프로필은 다국어 `tiny-q5_1`입니다.
- 실제 segment와 word timestamp를 타이밍 권위로 사용합니다.
- 문장 길이만으로 시간을 새로 추정하지 않습니다.
- 알아듣기 어렵거나 anchor coverage가 낮은 cue는 검수 대상으로 남깁니다.
- 인터넷 API, 계정, API 키가 필요 없습니다.

최초 한 번:

```bash
npm run caption-stack:doctor
npm run caption-stack:setup
npm run caption-stack:start
```

다음 작업부터:

```bash
npm run caption-stack:start
```

상태와 종료:

```bash
npm run caption-stack:status
npm run caption-stack:stop
```

기본 Tiny보다 무거운 모델을 원할 때만 다음 프로필을 명시적으로 설치합니다.

```bash
npm run caption-stack:setup -- --profile light
npm run caption-stack:setup -- --profile quality
```

저사양 기기에서는 `draft`를 유지하고 활성 컷을 16개 이하의 작은 묶음으로 나누는 편이 안전합니다.

### AudSeg: 모델 없는 빈 타이밍

AudSeg는 음성을 글로 바꾸지 않습니다. 브라우저에서 오디오 활동 구간을 찾고 각 구간에 비어 있는 편집용 cue를 만듭니다.

- 모델 다운로드와 companion 실행이 필요 없습니다.
- 20ms RMS 프레임, 적응형 소음 바닥, 히스테리시스, debounce·padding·merge를 사용합니다.
- 긴 활동 구간은 조용한 골짜기를 우선해 최대 4초 단위로 나눕니다.
- 결과는 같은 입력에서 재현 가능하며 네트워크 요청을 하지 않습니다.
- 음악, 효과음, 박수, 키보드 소리도 활동으로 감지될 수 있습니다.
- 화자 구분과 자막 텍스트는 제공하지 않습니다.

AudSeg는 “정확도가 낮은 STT”가 아니라 “수동 자막용 타이밍 스캐폴드”입니다. 모든 cue를 원음과 대조하고 텍스트를 직접 채워야 합니다.

### 어떤 방식을 고를까

| 목적 | 선택 |
|---|---|
| 한국어 글 초안과 실제 STT 타임스탬프가 필요함 | 로컬 Whisper |
| 글은 직접 쓰고 소리 구간만 빠르게 펼치고 싶음 | AudSeg |
| companion을 설치할 수 없는 환경 | AudSeg |
| 음악·효과음이 많고 발화만 구분해야 함 | 로컬 Whisper 후 사람 검수 |

방식을 바꾸면 체크포인트 지문도 달라집니다. 다른 방식의 완료 컷을 같은 결과로 오인해 건너뛰지 않습니다.

## 초벌 실행과 재개

한 번에 활성 컷은 최대 16개이며 새 초벌 cue는 최대 10,000개입니다. 실행 전 컷 수, 총 길이와 선택 방식을 확인합니다.

- Whisper를 고르면 companion 연결과 실제 모델을 확인한 뒤 오디오를 추출합니다.
- AudSeg를 고르면 companion 연결 없이 브라우저에서 바로 분석합니다.
- 취소하면 아직 시작하지 않은 컷은 처리하지 않습니다.
- 컷 하나가 끝날 때마다 프로젝트와 체크포인트를 저장합니다.
- 오류나 탭 종료 뒤 같은 범위·방식·pipeline 지문으로 다시 실행하면 완료 컷을 건너뜁니다.
- 새 전체 실행, 다른 원본 연결, 컷 범위 변경, 방식 변경은 낡은 체크포인트를 재사용하지 않습니다.

사람이 직접 만든 자막과 사람이 수정한 AI 자막은 재실행으로 덮어쓰지 않습니다.

## 자막 초안 규칙

Whisper 자동 본문 cue와 AudSeg 자리표시자 cue의 기본 화면 위치는 아래 중앙입니다.

- `x=0.5`, `y=0.84`
- 배경 없는 한 줄
- 기본 글꼴 Pretendard ExtraBold
- 한 cue 최대 4초
- 가능한 표시 시간 0.65초 이상
- 한국어 폭 20 단위 이하
- 목표 읽기 속도 초당 16폭 단위 이하
- 문장 끝 `.` 제거
- `?`, `!`, `…`, `~` 유지
- 기본 화자 흰색
- 식별 가능한 다른 화자는 결정적인 고유 색

**AI 자막 전체를 기본 위치로 정렬**은 AI origin 자막의 위치만 아래 중앙으로 맞춥니다. 텍스트, 시각, 레인, 색과 직접 만든 자막은 유지합니다. 평소 로딩과 재실행은 사람이 옮긴 자막 위치를 자동으로 되돌리지 않습니다.

## 자막 직접 검수

1. 각 cue를 재생하며 원음을 듣습니다.
2. 고유명사, 빠른 발화, 감탄사, 겹친 목소리를 확인합니다.
3. 노란 **검수 필요** 표시가 있으면 반드시 텍스트와 시간을 확인합니다.
4. 타임라인 블록 양끝 손잡이 또는 시작·끝 입력으로 시간을 조절합니다.
5. 화면 자막을 직접 끌거나 위치 버튼과 슬라이더로 배치합니다.
6. 화자별 색을 정합니다.

자막 레인은 기본 2개입니다. 같은 시각에 여러 자막을 올릴 수 있고 `+`로 레인을 늘릴 수 있습니다. 자막 트랙을 우클릭하면 현재 위치에 추가하고, 자막 블록을 우클릭하면 삭제할 수 있습니다.

색상 선택기 오른쪽 레지스터는 고정 흰색 `#FFFFFF`와 최근 사용한 비흰색 5개를 기억합니다. 레지스터 색을 누르면 선택 자막에 즉시 적용됩니다.

## 이미지 에셋

웹에서 이미지 자체를 복사한 뒤 편집기에서 `Ctrl/Cmd+V`를 누르면 현재 재생 위치에 들어갑니다. **클립보드 이미지 붙여넣기**와 파일 선택도 사용할 수 있습니다.

- PNG와 WebP의 투명 배경을 보존합니다.
- 위치, 크기, 불투명도와 표시 시간을 조절할 수 있습니다.
- 타임라인 블록 양끝을 끌어 시작·끝을 바꿀 수 있습니다.
- 붙여넣은 Blob은 프로젝트와 함께 IndexedDB에 저장됩니다.

### 자막과 에셋 시각 맞추기

타임라인 **자석**은 기본으로 켜져 있습니다. 자막 또는 에셋 경계를 가까이 끌면 같은 컷의 반대 종류 경계에 붙고 가이드가 나타납니다. 드래그 중 `Alt`를 누르면 그 드래그에서만 자석을 잠시 끕니다.

양끝을 완전히 같게 만들려면 같은 컷의 자막과 에셋을 차례로 선택한 뒤:

- 자막 패널의 **선택 에셋 구간에 정확히 맞춤**
- 에셋 패널의 **선택 자막 구간에 정확히 맞춤**

중 하나를 누릅니다.

## 구간별 음성

음성 트랙은 고정 1개입니다. 현재 위치에서 **+ 현재 위치 음성 설정**을 누르거나 음성 트랙을 우클릭해 설정 구간을 만듭니다.

- 구간 음량
- 완전 음소거
- 페이드 인
- 페이드 아웃
- 시작·끝

을 조절할 수 있습니다. 매우 짧은 단어 음소거는 파형만 믿지 말고 반복 재생해 앞뒤 음소까지 직접 확인하세요.

## 로컬 임시저장과 복구

- **지금 임시저장**: 즉시 스냅샷 생성
- 5분마다 자동 임시저장
- 프로젝트별 최근 5개 유지
- 복구본을 불러오기 직전 현재 상태를 `복원 직전`으로 자동 저장
- 사이드패널의 **이 기기의 최근 편집 → 계속 편집**으로 CURRENT 열기
- **복구본 선택**으로 최근 5개 목록 열기

프로젝트, 자막, 이미지 Blob, 파일 핸들, 임시저장은 현재 Chrome/Chromium 프로필의 IndexedDB에 있습니다. Extension 데이터를 지우거나 Extension을 제거하면 사라질 수 있으므로 중요한 작업은 프로젝트 JSON도 내보내세요.

## 영상 내보내기

**영상 내보내기**에서 폴더를 선택하면 다음 파일을 같은 폴더에 저장합니다.

- 편집 영상 MP4 또는 WebM
- 프로젝트 JSON
- 자막이 있을 때 SRT

같은 이름이 이미 있으면 덮어쓰지 않도록 새 이름을 제안합니다. 브라우저가 폴더 저장 API를 지원하지 않으면 파일별 다운로드로 폴백할 수 있습니다.

내보내기 전 확인:

- 모든 컷의 시작과 끝
- 내부 삭제 뒤 자막·에셋·음성 싱크
- 모든 AudSeg 자리표시자 제거 또는 실제 문구로 교체
- Whisper 검수 경고
- 화자 색과 자막 위치
- 음소거 경계
- 투명 에셋
- 저작권·음원·출연자 정책

## 권한과 네트워크

Extension은 치지직·YouTube 페이지 연결, 로컬 저장, 클립보드 이미지 읽기와 loopback companion 연결에 필요한 권한만 사용합니다.

- Whisper companion: `http://127.0.0.1` 또는 `http://localhost`
- AudSeg: 브라우저 내부 처리
- 원격 자막 호스트 권한: 없음
- 자막 API 키 입력: 없음
- 원본 업로드: 없음

Whisper session token은 companion 프로세스와 현재 편집기 탭 메모리에만 있으며 프로젝트, 임시저장, Chrome 저장소, 로그에 기록하지 않습니다.

## 문제 해결

### 사이드패널이 소스 탭을 찾지 못함

지원 영상 페이지가 최상위 탭에 열려 있는지 확인하고 한 번 새로고침합니다. 광고 중인 YouTube라면 광고가 끝난 뒤 다시 시도합니다.

### 원본 연결 뒤 싱크가 맞지 않음

**페이지 시각 ↔ 로컬 원본 정렬** 오프셋을 확인합니다. 다른 인코딩 파일을 연결했다면 파일의 시작 지점과 재생 길이가 같은지 먼저 확인합니다.

### Whisper 엔진이 꺼졌다고 나옴

```bash
npm run caption-stack:status
npm run caption-stack:start
```

설정이 없으면 `npm run caption-stack:setup`을 먼저 실행합니다. 4318 또는 4319 포트를 다른 프로세스가 쓰고 있으면 그 프로세스를 정상 종료한 뒤 다시 시작합니다.

### Whisper가 영어처럼 인식함

`.en` 모델이 아니라 다국어 모델인지 확인합니다. 기본 프로필로 복구:

```bash
npm run caption-stack:setup -- --profile draft
```

### AudSeg cue가 너무 많음

음악과 효과음도 활동으로 감지되는 것이 정상입니다. 필요 없는 cue를 지우거나 Whisper를 사용하세요. AudSeg 결과를 전사 결과처럼 간주하지 마세요.

### AudSeg cue에 실제 글이 없음

정상 동작입니다. AudSeg는 타이밍만 만들고 모든 텍스트는 사람이 채웁니다.

### 자막 시작·끝을 바꿀 수 없음

자막 블록 본문이 아니라 양끝 손잡이를 잡았는지 확인합니다. 정밀 값은 선택 자막 패널의 시작·끝 입력에 직접 넣을 수 있습니다.

### 내보내기가 느리거나 메모리가 부족함

다른 무거운 앱을 닫고 컷을 작은 프로젝트로 나눕니다. 긴 원본 전체를 메모리에 올리지는 않지만 인코딩 자체에는 CPU·GPU와 프레임 버퍼가 필요합니다.

### 저장된 원본을 다시 열 수 없음

브라우저의 파일 권한이 만료된 것입니다. 프로젝트는 그대로 둔 채 **원본 연결**에서 같은 파일을 다시 고릅니다. 오래된 복구본부터 강제로 불러오지 마세요.

## 알려진 제한

- Whisper와 AudSeg 결과는 모두 초안이며 사람 검수가 필요합니다.
- Whisper Tiny는 고유명사, 겹친 음성, 빠른 말과 잡음에 약할 수 있습니다.
- AudSeg는 발화와 음악·효과음을 구분하지 않고 텍스트나 화자를 만들지 않습니다.
- 자막 자동 생성은 활성 컷 16개와 컷당 30분 상한이 있습니다.
- 원본 디코더와 브라우저 인코더 지원은 코덱과 환경에 따라 다릅니다.
- 게시 가능 여부, 음원, 수익화와 제3자 권리는 자동 승인하지 않습니다.
