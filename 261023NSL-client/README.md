# 담다 · 고객용 테이블 주문

한국어·영어·일본어·중국어로 메뉴를 고르고 음성으로 요청하는 React Native Web 키오스크입니다. 고객 UI와 서버 측 게이트웨이를 포함하며, 주문 처리·네이버 클라우드 API·영속 저장은 [직원용 서버](../261023NSL-server/)가 담당합니다. 네이티브 Android/iOS 앱은 포함하지 않습니다.

## 기능

- 언어 선택, 테이블 번호, 메뉴 상세·알레르기 표시, 장바구니와 주문 내역
- 일반 **말로 요청** 버튼은 **말로 주문** 모드로 시작합니다. **직원 호출** 탭은 인식한 원문을 직원에게 전달합니다.
- 주문 확인 화면의 **추가 요청**은 직원 호출로 열리며, 요청 후 기존 주문 확인으로 돌아갑니다.
- 사용자 버튼 조작으로만 녹음하고 최대 25초의 16kHz 모노 PCM WAV를 생성합니다. 텍스트 입력창은 제공하지 않습니다.
- 수량·합계 확인 후 명시적으로 승인해야 음식 주문이 생성됩니다. 직원 요청의 로봇 전달은 직원 화면에서 별도로 승인합니다.
- 서명된 HttpOnly 쿠키로 고객 세션을 구분하고, 공개 게이트웨이는 허용된 고객 API만 중계합니다.

## 실행

Node.js 22.13 이상이 필요합니다. 테스트까지 실행할 때는 Node.js 24 이상을 권장합니다.

```sh
npm run install:ci
cp .env.example .dev.vars
npm run dev -- --port 5173
```

`.dev.vars`를 본인의 서버 설정으로 채운 뒤 실행합니다. 빈 템플릿만으로는 API가 연결되지 않습니다. 실행 로그에 표시된 로컬 주소를 열고 `?table=07`처럼 테이블 번호를 지정할 수 있습니다. 실제 마이크는 HTTPS 또는 브라우저가 허용하는 localhost 보안 컨텍스트가 필요합니다.

```sh
npm run build
npm start -- --port 5173
```

이 명령은 로컬 실행·빌드용이며 원격 서비스를 배포하지 않습니다. Sites/Cloudflare 실행 프로필과 도구 설명은 [SETUP-SITES.md](SETUP-SITES.md)를 참고하세요. 게이트웨이는 HTTPS 백엔드 원본 주소만 허용하므로 클라이언트의 전체 연동에는 HTTPS 서버가 필요합니다. 로컬 UI 실행과 모의 테스트는 별도로 할 수 있습니다.

## 설정

[.env.example](.env.example)의 값은 모두 비어 있습니다. 개발 값은 Git에서 제외된 `.dev.vars`에, 배포 값은 호스팅의 서버 비밀 설정에 넣습니다. NCP API 키는 이 프로젝트에 넣지 않습니다. 아래 값도 브라우저 공개 변수나 `NEXT_PUBLIC_*`로 옮기지 마세요.

| 이름 | 용도 |
| --- | --- |
| `DAMDA_BACKEND_URL` | 비공개 서버의 HTTPS 원본 주소. 경로·쿼리는 제외 |
| `DAMDA_BACKEND_TOKEN` | 비공개 Sites 서버에 접근할 서비스 자격 증명. `OAI-Sites-Authorization`에 사용 |
| `DAMDA_GATEWAY_SECRET` | 서버와 동일하게 설정하는 최소 32자 게이트웨이 공유 비밀 |
| `DAMDA_COOKIE_SECRET` | 최소 32자의 별도 고객 쿠키 서명 비밀 |

`.openai/hosting.json`은 D1/R2 바인딩이 없는 중립 매니페스트입니다. 배포 프로젝트 식별자나 운영 자격 증명은 포함하지 않습니다.

## 테스트

```sh
node --experimental-strip-types --test tests/*.test.mjs
npx tsc --noEmit
```

테스트는 모의 응답과 로컬 Worker 런타임으로 게이트웨이 접근 경계, 리다이렉트 차단, 녹음 취소·PCM 인코딩을 확인합니다. 실제 NCP 호출이나 물리 마이크 입력은 하지 않습니다.

## 범위와 한계

Speech·번역·주문 해석은 별도 서버와 본인의 API 설정이 있어야 동작합니다. 소음·발음·메뉴 이름에 따라 음성 인식이 틀릴 수 있으므로 화면에서 장바구니를 확인해야 합니다. 현재 음성 출력(TTS)은 비활성화되어 있으며, 결제·실제 로봇 제어·주방 장비는 구현 범위에 포함하지 않습니다. 전체 주문 시스템을 로컬 단독 모드로 대체하는 데모 API는 없습니다.
