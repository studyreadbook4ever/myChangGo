# 테스트와 실기기 점검

이 문서는 재현 가능한 검증 절차입니다. 절차가 적혀 있다는 사실은 해당 검사가
모든 기기에서 통과했다는 의미가 아닙니다. 실제 실행 결과는 릴리스 검증 기록과
빌드 테스트 보고서를 함께 확인하세요.

## 자동 검사

```sh
python3 tools/generate_fixtures.py --check
python3 -m unittest discover -s tools -p 'test_*.py' -v
./gradlew testDebugUnitTest lintDebug
./gradlew connectedDebugAndroidTest
```

마지막 명령은 연결한 Android 기기 또는 실행 중인 에뮬레이터가 필요합니다.
에뮬레이터는 파일 처리와 코덱 동작을 확인하는 데 유용하지만 실제 마이크 음질,
제조사 배터리 제한, 장시간 발열 시험을 대체하지 않습니다.

단위 검사는 누적 시간, 중복 일시정지/재개, 정지 중 종료, 다음 녹화에서의 시간
초기화를 확인합니다. 녹화 계측 검사는 실제 인코더 출력의 크기·색상·상하 방향,
슬라이드 변경, 정지 구간 제외, 오디오 트랙, 짧은 녹화 정리, 연속 녹화와 실패 후
복구를 확인합니다. PDF 계측 검사는 정상·비정상 파일과 비율·페이지 회전을 다룹니다.

## 발표 흐름

1. `demo.pdf`를 기기에 복사하고 앱의 파일 열기로 가져옵니다.
2. 3장의 슬라이드가 순서대로 보이는지 확인하고 각 장의 대본을 입력합니다.
3. 첫 장에서 이전, 마지막 장에서 다음 버튼을 반복해도 범위를 벗어나지 않아야 합니다.
4. 슬라이드마다 대본을 수정하고 앞뒤로 이동하여 수정 내용이 유지되는지 확인합니다.
5. 녹화 시작, 슬라이드 변경, 일시정지, 페이지 변경, 재개, 종료를 차례로 수행합니다.
6. 저장된 영상을 갤러리/영상 앱에서 재생합니다. 슬라이드와 음성만 들어 있고
   대본·조작 버튼·상태 표시줄이 없는지 확인합니다.
7. `demo-4x3.pdf`, `demo-portrait.pdf`, `demo-rotated.pdf`로 반복합니다.
   각 페이지의 종횡비가 유지되고 회전 상태가 맞아야 합니다.

## 녹화 결과 판정

예를 들어 **녹화 3초 → 정지 4초 → 녹화 3초 → 종료**를 수행합니다.
저장된 영상 길이는 인코더 준비/버튼 입력 오차를 고려해 약 6초여야 합니다.
정지 중 4초의 무음 영상이 추가되면 안 됩니다. 재개 후 음성과 영상이 맞아야 합니다.

```sh
ffprobe -v error -show_entries stream=index,codec_type,codec_name,width,height,duration \
  -show_entries format=duration -of json recording.mp4
```

영상 스트림이 1280×720이고, 마이크를 켰다면 오디오 스트림도 있어야 합니다.
`ffprobe`가 스트림을 읽는 것만으로 영상/음성 품질 검증이 끝나는 것은 아닙니다.
시작·페이지 변경 전후·재개 직후·마지막 프레임을 직접 확인하고 음성도 듣습니다.
PDF 렌더링 프레임과 디코딩한 MP4 프레임의 비교에는 손실 압축 오차를 허용하되,
대본에 넣은 `PRIVATE_SCRIPT_` 문자열과 녹화 UI는 보여서는 안 됩니다.

## 오류 및 상태 변경

| 상황 | 기대 결과 |
| --- | --- |
| 확장자만 PDF / 손상 PDF | 오류를 안내하고 앱이 계속 반응함 |
| 암호화된 PDF | 암호 없는 PDF가 필요하다는 오류 안내 |
| 100 MB 초과 파일 | 메모리에 올리기 전에 거부 |
| 마이크 권한 거부 | 무음 녹화를 선택할 수 있고 허가 없이 마이크에 접근하지 않음 |
| 짧게 시작 후 즉시 종료 | 손상 파일을 정상 저장으로 표시하지 않음 |
| 일시정지 상태에서 종료 | 이미 녹화한 부분을 종료·저장하며 멈춰 있지 않음 |
| 녹화/종료 연속 탭 | 중복 인코더나 중복 저장 없음 |
| 홈/앱 전환/화면 잠금 | 녹화 상태를 안전하게 정리하고 백그라운드에서 계속 녹음하지 않음 |
| 저장 공간 부족 | 저장 실패를 알리고 완성된 원본을 보관해 재시도. 녹화 자체가 실패한 불완전 파일은 정리함 |
| 앱 종료 후 재실행 | 대본 복구 동작을 확인하고 손상 상태면 안내 |
| 20분 이상 실제 발표 | 발열·메모리·배터리·음성 싱크·저장 공간을 실제 휴대폰에서 확인 |

실기기 권장 확인: 지원 최소 Android 버전 기기 1대와 최신 버전 기기 1대,
삼성 등 제조사 기기, 작은 화면, 태블릿, 유선/블루투스 마이크, 권한 거부 후 재허용.
실행하지 않은 기기/조합은 검증 완료로 표시하지 않습니다.
