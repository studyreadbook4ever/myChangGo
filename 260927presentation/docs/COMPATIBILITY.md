# PDF 호환성과 녹화 범위

이 앱은 휴대폰에서 PDF 발표 자료를 열고, 대본을 보며 슬라이드와 마이크 음성만
녹화하는 도구입니다. PowerPoint 등에서 만든 발표 자료는 **슬라이드만 PDF로
내보낸 뒤** 여세요. PDF의 한 페이지를 슬라이드 한 장으로 사용합니다.

| 항목 | 처리 범위 / 제한 |
| --- | --- |
| 입력 | 암호 없는 PDF. Android `PdfRenderer`로 표시 |
| 페이지 순서·비율 | 원본 순서와 종횡비 유지, 16:9 바깥 여백 허용 |
| 텍스트·도형·사진·차트 | PDF에 저장된 정적 페이지 모습으로 표시 |
| 글꼴 | PDF 렌더러의 임베디드 글꼴/기기 대체 글꼴 지원 범위. 앱이 상용 글꼴을 배포하지 않음 |
| 발표자 대본 | 앱에서 페이지별로 입력. PDF에서 노트를 자동 추출하지 않음 |
| 페이지 회전 | PDF 페이지의 회전 정보를 렌더러에서 반영 |
| 애니메이션·전환·동영상·오디오 | PDF의 정적 페이지 녹화만 지원. 문서 내부 스크립트나 미디어를 재생하지 않음 |
| 암호화된 PDF | 지원하지 않음. 암호 없이 내보낸 PDF 필요 |
| PPT/PPTX/문서/이미지 직접 열기 | 지원하지 않음. PDF로 변환 필요 |
| 입력 크기 | 최대 100 MB. 전체 페이지를 메모리에 올리지 않고 현재 페이지만 렌더링 |

PDF를 만들 때 **노트 페이지를 포함하지 마세요**. PDF 페이지에 대본을 함께
인쇄했다면 그 대본도 슬라이드의 일부이므로 영상에 보입니다. 암호나 인쇄 제한을
해제할 때는 문서 소유자가 허용한 방법을 사용하세요.

녹화는 1280×720(16:9) MP4를 생성합니다. 원본이 4:3이나 세로 비율이면 내용이
찌그러지지 않도록 여백을 둡니다. 대본·이전/다음·녹화 버튼이 있는 전체 화면을
캡처하는 방식이 아니라 슬라이드 비트맵을 영상 인코더에 전달합니다. 시스템
알림과 조작 영역을 영상에 포함하도록 설계하지 않았습니다.

마이크를 켜면 Android 마이크 권한이 필요합니다. 권한을 허용하지 않아도
마이크를 끄고 무음 영상을 녹화할 수 있습니다. 마이크 품질, 블루투스 장치 선택,
다른 앱의 녹음과의 충돌, 제조사별 코덱 차이는 실제 기기에서 확인해야 합니다.
일시정지 구간은 최종 영상의 재생 시간에서 제외합니다.

호환성 확인용 자료는 [samples](../samples/README.md)에 있습니다. 테스트 범위와
실기기 점검 항목은 [TESTING.md](TESTING.md)를 참조하세요.
