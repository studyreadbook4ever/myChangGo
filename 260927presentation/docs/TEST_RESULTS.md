## 확인한 동작

- 첫/마지막 페이지, 16:9·4:3·세로·초광폭·회전·혼합 크기 PDF
- 확장자와 무관한 내용 판별, 파일 이름 변경 후 동일한 대본 키 유지
- 빈 파일·손상 PDF·PDF로 위장한 내용·100 MB 초과 파일 거절
- 잘못된 페이지·이미지 크기, 동시 페이지 요청, 반복 열기/닫기 및 파일 디스크립터 정리
- 문서 공급자 메타데이터와 실제 내용 가져오기, 실패한 가져오기 임시 파일 정리
- 대본 저장·페이지 이동·Activity 재생성 후 복원
- 마지막 문서/페이지 복원과 가져오기 실패 시 기존 자료 유지
- 1280×720 H.264 출력, 음성 켜기 시 AAC 샘플, 무음 녹화 시 오디오 트랙 없음
- 디코딩된 영상 픽셀의 색상·상하 방향·슬라이드 변경 확인
- 미리보기 PDF 비트맵과 MP4 프레임 비교: 대본과 앱 조작 영역이 영상에 섞이지 않음
- 일시정지 구간을 뺀 재생 시간, 정지 중 페이지 변경 후 재개, 정지 상태에서 종료
- 너무 짧은 녹화 거절 후 다음 녹화 성공, 기존 파일 덮어쓰기 방지, 연속 녹화
- 종료 직후 리소스를 해제해도 완료된 MP4 보존
- 앱이 `onStop`으로 이동할 때 녹화를 종료하고 MediaStore 갤러리에 저장

## 환경과 원본 기록

JDK 21, Gradle 8.10.2, Android Gradle Plugin 8.7.3, Kotlin 1.9.24,
compile/target SDK 35, min SDK 29. 에뮬레이터는 x86_64, Pixel 2 화면 크기,
SwiftShader EGL과 플랫폼 미디어 코덱을 사용했습니다.

- [Android 15 원본 계측 로그](test-results/android-15.txt)
- [Android 10 원본 계측 로그](test-results/android-10.txt)
- [배포 APK 녹화 파일 분석](test-results/release-smoke.json): 1280×720 H.264 + AAC, 4.223초
- [APK SHA-256](APK_SHA256.txt)

Android 15 ATD 이미지는 일반 홈 런처와 기본 화면 그리기를 생략합니다.
수명주기 테스트는 `ActivityScenario`로 `onStop`을 실행했고, 화면 점검 때는
테스트 프로세스의 그리기를 활성화했습니다. 공개 APK에 테스트 provider는
들어가지 않습니다. 테스트 provider만 별도 프로세스에서 동작하도록 Java로
작성했으며, 배포 앱의 구현 코드는 Kotlin입니다.

Lint 경고 8개는 최신 테스트 의존성 버전 안내 4개, 발표용 가로 화면 제한 1개,
Android 11 이하의 추가 백업 설정 권고 1개, 한국어 화면 문자열의 다국어 리소스 분리 안내 2개입니다. Android 11 이하에는 이미 `allowBackup=false`가 적용되어 있습니다. 런타임 오류로
간주되는 Lint 항목은 없습니다.

## 아직 확인하지 않은 범위

실제 휴대폰은 연결되어 있지 않았습니다. 제조사별 PDF/코덱 차이, 실제 마이크
음질·블루투스·전화 수신, 20분 이상 녹화의 발열/배터리/음성 싱크,
저장 공간이 실제로 소진되는 상황은 실기기에서 추가 확인해야 합니다.
모든 PDF와 모든 Android 기기에서 무결함을 보장한다는 의미는 아닙니다.
