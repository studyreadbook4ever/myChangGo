총 **1,000개 어휘**, 별도 **300자 기초·연결 한자 카드**.

N1 목표라도 처음에는 N5·N4에서 이미 아는 소리와 낯선 한자 모양을 연결하세요. 이후 N3→N2→N1으로 넘어갑니다.

이 자료는 공식 JLPT 목록이 아닙니다. 특히 N1 300개는 독해 중심의 선별 핵심 어휘이며 N1 전체 범위를 담지 않습니다.
