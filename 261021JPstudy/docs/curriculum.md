# N1을 향한 한자 학습 순서

일본어를 들으면 아는 단어인데 글자로 보면 막히는 한국인 학습자를 위한 **1,000개 선별 어휘와 300자 한자 카드**입니다. 처음부터 모든 음독·훈독을 암기하기보다 **이미 아는 소리 → 단어의 한자 모양 → 문장 속 의미**를 연결합니다.

## 수록 범위

| 순서 | 추정 단계 | 단어 수 | 주된 연결 | 단어장 |
|---|---|---:|---|---|
| 1 | N5 | 180 | 숫자·사람·요일·장소·기초 동작 | [N5](wordbooks/N5.md) |
| 2 | N4 | 160 | 생활 물건·학교·건강·자동사와 타동사 | [N4](wordbooks/N4.md) |
| 3 | N3 | 160 | 회사·사회·감정·정보·추상적 표현 | [N3](wordbooks/N3.md) |
| 4 | N2 | 200 | 설명문·업무·제도·논리 관계 | [N2](wordbooks/N2.md) |
| 5 | N1 | 300 | 논증·정책·경제·변화·정밀한 동사 | [N1](wordbooks/N1.md) |

N등급은 편집상 학습 순서를 나타내는 **비공식 추정**입니다. 익숙한 단어라도 글자 자체는 어려울 수 있으며, N1 묶음에는 고급 글을 읽기 위해 다시 익힐 만한 쉬운 표현도 들어 있습니다. JLPT는 공식 단어·한자·문법 출제 목록을 공개하지 않습니다. 이 목록은 N1 전체 어휘나 출제 보장 목록이 아닙니다. [JLPT 공식 FAQ](https://www.jlpt.jp/e/faq/)

N1은 논리적·추상적인 글의 구조와 내용을 이해하는 능력도 요구합니다. 따라서 이 앱의 단어 학습과 함께 긴 글 읽기, 문법, 청해, 공식 형식의 문제 연습을 이어 가야 합니다. [JLPT 급수별 능력 설명](https://www.jlpt.jp/e/about/levelsummary.html)

## 처음 시작하는 방법

1. **N1 목표를 유지한 채 N5부터 시작합니다.** 목표 급수는 학습 범위를 정합니다. 새 단어는 기초부터 올라오므로 아는 말을 한자와 연결하는 시간을 먼저 확보합니다.
2. **하루 새 단어 10개로 시작합니다.** 정답을 보기 전에 읽기를 소리 내어 떠올립니다. 이미 아는 소리가 떠오르면 새로운 뜻까지 처음부터 외울 필요가 줄어듭니다.
3. **읽기와 뜻을 따로 확인합니다.** 뜻만 알지만 읽지 못하는 단어와 소리는 알지만 뜻을 모르는 단어를 구별합니다. 답을 본 뒤 알아보는 것은 스스로 떠올린 것과 다릅니다.
4. **다음 날은 예정 복습부터 합니다.** 복습이 쌓이면 새 단어 수를 줄입니다. 하루 빠졌다고 밀린 양을 한 번에 외우려 하지 말고, 현재 기억 상태에 맞게 평가합니다.
5. **외운 단어를 예문에서 다시 읽습니다.** 전체 히라가나 읽기를 가린 상태에서 읽고, 어려운 부분만 확인합니다. 단어 하나를 아는 것과 문장 전체를 이해하는 것은 별도 연습이 필요합니다.

간격을 두고 기억에서 꺼내는 연습을 반복하는 학습 원칙을 참고했습니다. 하루 10개나 앱의 구체적인 복습 간격이 모든 사람에게 최적이라는 뜻은 아닙니다. 자기 평가와 실제 읽기 성과에 맞춰 양을 조절하세요. [외국어 어휘 회상 단서와 기억에 관한 연구, PNAS](https://doi.org/10.1073/pnas.2413511121)

## 한국어를 활용하는 요령

**한국 한자어의 뜻을 일본어 소리와 연결합니다.** 学은 '배울 학', 学生은 がくせい, 学校는 がっこう입니다. 한국어 지식은 의미를 붙이는 데 활용하고, 일본어 발음은 실제 단어 단위로 익힙니다. 한국 한자음을 기계적으로 바꾸는 공식으로 읽지 않습니다.

**일본 신자체를 따로 알아봅니다.** 學→学, 國→国, 體→体, 讀→読처럼 모양이 달라진 글자가 있습니다. 카드의 한국 훈음은 대응 한자의 의미를 잇는 보조 정보이며 일본어 발음이 아닙니다.

**짧은 말부터 여러 읽기를 연결합니다.** 人은 ひと, 韓国人에서는 じん, 三人에서는 にん입니다. 日도 日曜日·毎日·一日에서 읽기가 달라집니다. 모든 읽기를 먼저 외우기보다 지금 보는 단어의 읽기를 먼저 정확하게 기억합니다.

**통째로 읽는 단어는 따로 취급합니다.** 今日(きょう), 明日(あした), 一日(ついたち), 二十日(はつか)은 글자별 음을 이어 읽기 어렵습니다. 一日은 날짜 '1일'일 때 ついたち, 기간 '하루'일 때 いちにち이므로 예문까지 함께 익힙니다.

## 헷갈리는 묶음은 비교해서 읽기

| 구별할 묶음 | 확인할 것 |
|---|---|
| 開く・開ける / 閉まる・閉める | 저절로 일어나는 변화와 누군가 하는 행동 |
| 増える・増やす / 減る・減らす | 수가 늘거나 줄어드는 것과 수를 늘리거나 줄이는 것 |
| 早い・速い | 시간이 이름과 속도가 빠름 |
| 易しい・優しい | 쉬움과 상냥함 |
| 会社・社会 | 같은 두 글자의 순서와 읽기 |
| 以前・依然 | 이전과 여전히 |
| 追求・追究・追及 | 목표 추구·깊은 탐구·책임 추궁 |
| 一概に・一向に・決して・到底 | 뒤의 부정 표현까지 포함한 논리 |
| 表す・現れる・著す | 표현함·나타남·저술함 |

카드의 음독은 가타카나, 훈독은 히라가나로 표시합니다. 음독·훈독 목록은 **대표 읽기**이며 모든 읽기나 이름 읽기를 망라하지 않습니다. 뜻·문맥에 따라 달라지는 읽기는 어휘 카드의 예문과 주의를 우선합니다.

기억 힌트는 반복되는 단어, 대비되는 모양, 한국 훈음을 활용한 암기 보조입니다. **역사적 어원 설명이 아닙니다.** 글자 모양을 이용한 이야기나 시각적 연상을 사실상의 어원으로 외우지 않도록 모든 한자 힌트에 이를 표시했습니다.

## 사전형과 실제 표기

동사는 사전형을 표제로 사용하며 예문에서는 문맥에 맞게 활용됩니다. 의미는 학습에 필요한 대표 뜻을 먼저 적고 `;` 뒤에 다른 주요 뜻을 덧붙였습니다. 예문 번역은 해당 문장의 뜻입니다.

한자 형태를 알아보는 연습을 위해 予め・予て・遣り甲斐처럼 실제 글에서는 가나 표기도 자주 쓰이는 단어를 포함했습니다. 관련 카드에 가나 표기 설명을 붙였습니다. 한자를 쓸 수 있다는 사실과 그 한자 표기가 일상에서 가장 흔하다는 주장은 다릅니다.

일부 명사군의 예문에는 동일한 문장 틀을 사용했습니다. 익숙한 문장 구조에서 목표 단어만 바꿔 읽도록 만든 연습이며, 그 단어의 모든 용법을 보여주는 것은 아닙니다. 특히 N1 300개에는 각 단어의 결합 관계를 보여주는 개별 예문을 제공합니다.

## 한자 카드의 상세 범위

어휘 표기에 등장하는 한자는 **837자**입니다. 그중 **292자**에 상세 한자 카드가 있으며, 확장 학습을 위한 8자를 더해 총 **300자**를 제공합니다.

- 1,000개 중 **388개 단어**는 포함된 모든 한자의 상세 카드가 있습니다.
- **723개 단어**는 적어도 한 글자의 상세 카드가 있습니다.
- 나머지 글자도 어휘의 읽기·한국어 뜻·예문은 제공하지만 개별 글자의 훈음·음독·훈독 해설은 아직 없습니다.

이는 기초에서 고급으로 읽기를 연결하는 선별 자료입니다. N1에 필요한 모든 한자를 다룬 한자사전은 아닙니다. `python3 tool/validate_curriculum.py --json`으로 상세 적용 범위와 빠진 글자의 빈도를 확인할 수 있습니다.

## 데이터 검증과 편집

원본은 [tool/build_curriculum.py](../tool/build_curriculum.py) 안의 직접 작성한 어휘·예문·한자 설명입니다. 앱 JSON과 Markdown 단어장은 같은 원본으로 생성합니다. 단어 ID는 표기와 읽기에 기반하므로 단어 순서나 추정 레벨을 조정해도 바뀌지 않습니다. 표기·읽기 자체를 고치는 경우 ID가 바뀌므로 기존 학습 기록의 이전 여부를 별도로 검토해야 합니다.

```sh
python3 tool/build_curriculum.py
python3 tool/build_curriculum.py --check
python3 tool/validate_curriculum.py
python3 tool/validate_curriculum.py --json
```

검증기는 필수 필드, 고유 ID, 중복 단어, 급수와 순서, 히라가나 읽기, 예문 읽기 문자, 한국어 조사 잔여 표기, 한자 카드 중복, 음독·훈독 문자, 수량과 한자 카드 적용 범위를 검사합니다. 표제어가 그대로 나온 **984개 예문**은 해당 읽기가 문장 읽기에도 들어 있는지 추가로 확인합니다. 활용형과 번역의 자연스러움은 자동 검사만으로 보장할 수 없어 별도 언어 검수를 진행했습니다.

전체 1,000개 어휘 및 최초 223개 한자 카드에 독립적인 읽기·뜻·예문 검수를 실시했습니다. 이후 추가한 77개 한자 카드는 작성자 검토와 구조 검증을 거쳤습니다. `究明` 한국어 풀이, `為替` 대표 뜻, `授業` 설명 등 발견한 문제를 수정했습니다. 오류 제보 시 표제어와 문장을 함께 알려 주면 원본과 생성 파일을 동시에 고칠 수 있습니다.
