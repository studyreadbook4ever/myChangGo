# 한자 잇다 · 261021JPstudy

**아는 소리에, 한자를 잇다.** 일본어를 들으면 어느 정도 이해하지만 한자는 처음인 한국인 학습자를 위한 Flutter 앱입니다. 목표는 N1, 학습 순서는 기초부터입니다.

N5→N1 선별 어휘 **1,000개**, 한자 풀이 **300자**, 한국어 뜻, 히라가나 읽기, 예문, 한국식 훈음 연결을 한 화면에서 볼 수 있습니다. 계정·서버 없이 단어장과 학습 기록을 기기에 저장합니다.

## 설치

1. 맨 위 APK 링크를 Android 기기에서 엽니다.
2. 다운로드한 APK를 열고, Android가 요청하면 해당 브라우저/파일 앱의 ‘알 수 없는 앱 설치’를 허용합니다.
3. **한자 잇다**를 실행하고 `읽기 떠올리기`를 누릅니다.
4. 발음이 나오지 않으면 기기 TTS 설정에서 일본어 음성을 설치합니다. 다운로드한 음성이 오프라인을 지원하는지는 기기 엔진에 따라 다릅니다.

Android 7.0 이상을 지원하며 실제 검증 환경은 [테스트 기록](docs/testing.md)에 기재합니다. 업데이트는 같은 서명 키를 사용합니다. 앱 삭제 전에 `내 학습 → 백업 파일 저장`으로 기록을 보관하세요.

## 하루 학습 흐름

- **읽기:** 한자를 보고 읽기를 먼저 말해 봅니다. 정답 공개 전에는 히라가나·뜻·음성을 보여주지 않습니다.
- **연결:** 정답의 히라가나, 한국어 뜻, 예문, 한국 한자 훈음을 확인합니다. 한국 한자음은 의미 연결용이며 일본어 발음의 대체물이 아닙니다.
- **평가:** 정답을 보기 **전** 얼마나 기억했는지 `몰랐어요 / 어려웠어요 / 기억했어요 / 쉬웠어요`로 고릅니다.
- **뜻:** 같은 단어의 한국어 의미도 따로 떠올립니다. 읽기와 뜻의 복습 간격은 독립적입니다.
- **다음 날:** 예정된 복습을 먼저, 남은 한도만큼 새 단어를 배웁니다. 기본 하루 10개, 세션당 최대 20개 단어으로 시작합니다.

`몰랐어요` 카드는 같은 세션에서 뒤쪽에 다시 나옵니다. 한 단어당 세션 내 최대 3번으로 제한하며, 계속 어렵다면 다음 복습으로 넘깁니다. 세션이 끝나기 전에도 답변마다 즉시 저장합니다.

## 기능

| 화면 | 할 수 있는 일 |
| --- | --- |
| 오늘 | 예정 복습, 남은 새 단어 한도, 연속 학습일, 학습한 단어 확인 |
| 읽기·뜻 카드 | 정답 숨김, 네 단계 자기 평가, 독립적인 복습 간격, 일본어 정상/느린 발음 |
| 단어장 | 한자·히라가나·한국어 뜻·훈음 검색, N5~N1 필터, 저장한 단어·약점 필터, 읽기 가리기 |
| 단어 상세 | 예문·문장 읽기·번역, 기초 한자 훈음/음독/훈독과 연결 힌트 |
| 10문제 퀴즈 | 학습한 단어·다음 기초 단어의 읽기 퀴즈, 약점 우선, 정답 해설·오답 다시 보기 |
| 내 학습 | 목표 급수, 하루 새 단어 수, JSON 파일 백업·검증 후 복원, 학습 기록 초기화 |

퀴즈는 선택지를 통한 확인 연습입니다. 퀴즈 점수는 세션 내에서만 표시하고 복습 간격에는 반영하지 않습니다. `약점`은 카드 학습에서 가장 최근 `몰랐어요`로 평가한 읽기/뜻이 있는 단어입니다.

N1 목표를 기본으로 선택하되 새 단어는 N5부터 순서대로 제시합니다. 고급 어휘만 보고 싶을 때는 단어장 N1 필터를 사용하세요. `내 학습`에서 범위를 N5~N3 등으로 줄일 수도 있습니다.

## 단어장과 콘텐츠 범위

앱과 Markdown 단어장은 같은 원본 JSON에서 만들어집니다. [커리큘럼 설명·급수별 단어장](docs/curriculum.md)에서 브라우저로도 읽을 수 있습니다.

**공식 JLPT 출제 목록이나 N1 전 범위 완성본이 아닙니다.** 급수는 학습용 추정 분류이며, 단어의 일상적 난이도와 글자 자체의 난이도는 다를 수 있습니다. JLPT는 공식 단어·한자·문법 출제 목록을 공개하지 않습니다. [JLPT 공식 FAQ](https://www.jlpt.jp/e/faq/index.html)

예문·한국어 설명·기억 힌트는 이 프로젝트를 위해 작성했습니다. 기억 힌트는 암기용 연상이며 한자의 역사적 어원 설명이 아닙니다. 여러 읽기가 있는 글자는 해당 단어에서의 읽기를 우선합니다. 한자 풀이가 있는 글자의 상세 설명만 표시하며, 고급 어휘의 모든 글자를 해설하는 사전은 아닙니다.

## 복습 규칙과 기록

설명 가능한 **SM-2 참고 자체 스케줄러**를 사용합니다. FSRS 모델이나 학습 효과를 검증한 개인 최적화 모델을 주장하지 않습니다.

| 평가 | 처음 만난 카드 | 이후 |
| --- | --- | --- |
| 몰랐어요 | 10분 후 | 학습 단계 초기화, 같은 세션 재노출 |
| 어려웠어요 | 30분 후 | 학습 단계에 따라 짧게 재학습 또는 기존 간격 × 1.2 |
| 기억했어요 | 1일 후 | 3일, 이후 난이도 계수에 따라 연장 |
| 쉬웠어요 | 4일 후 | 더 큰 비율로 간격 연장 |

새 단어 한도는 하루에 처음 소개한 **서로 다른 단어 수**입니다. 그 단어의 다른 모드는 새 단어 한도를 다시 소비하지 않습니다. 복습 기한은 절대 시각으로, 연속 학습일·하루 통계는 기기 현지 날짜로 계산합니다. `익힌 단어`는 읽기·뜻 모두 21일 이상 간격에 도달한 단어이며 실제 영구 암기를 보장하는 지표는 아닙니다.

학습 기록은 SharedPreferences에 버전이 있는 JSON으로 저장합니다. 쓰기가 실패하면 화면의 진도도 진행시키지 않습니다. 손상되거나 맞지 않는 백업은 현재 기록을 바꾸지 않습니다. 초기화는 학습 기록과 복습 일정만 지우고 목표·새 단어 설정 및 저장한 단어는 유지합니다.

## 개발 및 검증

Flutter **3.47.7**, Dart **3.13.5**, Java **21** 기준입니다. 의존성 버전은 `pubspec.lock`에 고정했습니다.

```sh
cd 261021JPstudy
flutter pub get --enforce-lockfile
python3 tool/validate_curriculum.py
dart format --output=none --set-exit-if-changed lib test integration_test
flutter analyze
flutter test --concurrency=1
flutter run
```
