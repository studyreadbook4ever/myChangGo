# 261008balPyo

휴대폰에서 PPT 발표 대본을 한 장씩 읽는 Flutter Android 앱입니다.
화면 왼쪽을 누르면 이전 장, 오른쪽을 누르면 다음 장으로 이동합니다.
앱 소스, Android 프로젝트, 테스트와 빌드 스크립트가 이 디렉토리에 있습니다.

## 사용하기

1. 앱 오른쪽 위 **연필**을 누릅니다.
2. **전체 대본 붙여넣기**를 선택하고 대본을 넣습니다.
3. 장 사이에 `---`를 한 줄로 넣습니다. 첫 줄의 `# 제목`은 슬라이드 제목이 됩니다.
4. **이 대본으로 바꾸기**를 누른 다음 편집 화면 오른쪽 위 **저장**을 누릅니다.
5. 화면 좌우를 눌러 넘기며 발표합니다. 긴 대본은 위아래로 스크롤합니다.

```text
# 1. 발표 시작
안녕하세요. 오늘 발표할 내용은…

---

# 2. 연구 배경
이 주제를 선택한 이유는…
```

실제 발표 대본은 제공되지 않아 최초 실행에는 사용법 예시가 표시됩니다.
`examples/script.txt`는 형식을 보여주는 예시이며 사용자의 실제 대본이 아닙니다.
슬라이드를 하나씩 추가·수정·삭제하거나 손잡이로 순서를 바꿀 수도 있습니다.
`---`가 단독으로 있는 줄은 전체 붙여넣기에서 슬라이드 구분자로 사용합니다.

## 발표 화면

- 큰 글씨, 넓은 줄 간격, 어두운 화면 / 밝은 화면.
- 설정에서 글자 크기 18–46 조절 및 전체 대본 클립보드 복사.
- 발표 화면을 보고 있는 동안 화면 꺼짐 방지.
- 전체 화면, 발표 시간 시작·일시정지·초기화.
- 하단 장 번호를 눌러 원하는 슬라이드로 바로 이동.
- 첫 장과 마지막 장에서는 더 이상 넘어가지 않습니다.
- 대본, 글자 크기, 화면 색상과 마지막으로 읽은 장을 휴대폰에 저장.

타이머는 이번 앱 실행의 발표 시간을 측정하며 앱 종료 후에는 초기화됩니다.
대본은 장 이동 시에도 현재 휴대폰의 앱 전용 파일에 저장됩니다.
저장 실패가 발생하면 화면에 표시하며 재시도와 대본 복사를 사용할 수 있습니다.
전체 대본 복사는 텍스트 백업입니다. 앱 삭제 전에 필요한 대본을 복사해두세요.

## 실행 및 APK 빌드

기준 도구는 **Flutter 3.35.7 / Dart 3.9.2**, **JDK 17**입니다.
Android SDK 36, Build Tools 및 NDK 27.0.12077973를 준비합니다.
최소 지원 Android 버전은 Android 7.0(API 24)입니다.

```bash
cd 261008balPyo
flutter pub get
flutter run
```

검증 후 APK 생성:

```bash
bash tools/build_apk.sh
```

결과 파일은 `dist/261008balPyo.apk`입니다. 휴대폰에 복사해서 설치할 수 있습니다.
개인 설치용 APK는 release 모드로 최적화되며 개발용 키로 서명됩니다.
Play Store 배포에는 별도의 비공개 서명 키 설정이 필요합니다.
빌드 스크립트는 실제 Flutter 분석·테스트가 통과한 경우에만 APK 빌드를 진행합니다.
APK 파일과 로컬 SDK 경로, 서명 키는 Git에서 제외됩니다.

## 구현

UI와 앱 동작은 Dart/Flutter로 작성했습니다. Java의 `MainActivity`는
Android에서 Flutter를 띄우는 기본 진입점입니다.
Gradle의 `.kts` 파일과 플러그인 내부 Kotlin은 Android 빌드 도구 설정입니다.

```text
lib/
  main.dart        앱 진입점
  app.dart         테마, 데이터 로드와 저장 상태
  reader.dart      발표 화면, 좌우 터치, 설정과 타이머
  editor.dart      슬라이드 편집과 전체 대본 붙여넣기
  models.dart      대본 모델과 텍스트 변환
  storage.dart     순차 쓰기, 임시 파일 교체, 이전 버전 백업
android/          Android 빌드 프로젝트 및 Gradle Wrapper
test/             대본 변환, 저장 복구와 휴대폰 화면 동작 테스트
tools/            검증 및 APK 빌드 스크립트
examples/         붙여넣기 형식 예시
```

release 앱에는 인터넷 권한이 없으며 서버, 로그인, 분석 수집 기능이 없습니다.
대본과 설정은 기기의 앱 전용 JSON 파일에 저장됩니다.
손상된 저장 파일을 읽으면 이전 백업을 시도하며, 둘 다 읽을 수 없으면
원본을 보존하고 오류를 표시합니다. Android 자동 클라우드 백업은 사용하지 않습니다.

Gradle Wrapper는 Gradle 8.12의 공식 배포 파일이며 Apache License 2.0을 따릅니다.
