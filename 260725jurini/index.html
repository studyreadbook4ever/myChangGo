HOW IT WORKS

가볍게 만들고,
피드백은 잃지 않게.

  1. 1
    브라우저에서 규칙 기반 조립

    입력을 분류하고 Help Query v1을 만듭니다. 외부 AI로 보내지 않아요.

  2. 2
    어떤 LLM에도 복사

    사람용 프롬프트와 구조화된 스키마를 함께 제공합니다.

  3. 3
    피드백 선저장·후전송

    평가를 먼저 로컬 outbox에 보관하고, 수집기가 연결되면 자동 재전송합니다.
